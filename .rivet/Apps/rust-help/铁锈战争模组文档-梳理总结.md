## 三、INI 配置速查（核心价值）

### 3.1 模组目录结构

```
mod_folder/
├── mod-info.txt            # 模组元信息 [core] name/description/version/author
├── all-units.template      # 全局模板 / 全局资源定义
├── units/                  # 单位定义 *.ini
├── projectiles/            # 抛射体定义
├── effects/                # 效果定义
├── images/                 # 图像（units/ projectiles/ effects/）
└── maps/                   # 自定义地图
```

### 3.2 分区（section）总表

| 分区 | 作用 | 关键字段 |
|---|---|---|
| `[core]` | 单位/建筑本体 | name, class, price, maxHp, mass, techLevel, buildSpeed, radius, displayRadius, fogOfWarSightRange, armour |
| `[graphics]` | 外观与动画 | image / image_wreak / image_turret / image_back / image_shadow, teamColorsUseHue, teamColoringMode, total_frames, frame_width/height, animation_* |
| `[movement]` | 移动 | movementType, moveSpeed, maxTurnSpeed, reverseSpeedPercentage, targetHeight, landOnGround |
| `[attack]` | 攻击 | canAttack, canAttackFlying/Land/UnderwaterUnits, maxAttackRange, isFixedFiring, isMelee, mutator_* |
| `[turret_N]` | 炮塔 | x, y, projectile, turnSpeed, size, barrelX/Y, delay, warmup, limitingRange, interceptProjectiles_* |
| `[projectile_N]` | 抛射体 | directDamage, areaDamage, areaRadius, life, speed, drawType, color, ballistic, instant, spawnProjectilesOn* |
| `[leg_N]` | 腿部动画（步行单位） | x, y, image, image_end, moveSpeed, rotateSpeed, holdDisMin/Max |
| `[action_N]` / `[hiddenAction_N]` | 行为/隐藏行为 | text, description, price, buildSpeed, displayType, autoTrigger, addResources, spawnUnits, buildUnit, convertTo |
| `[effect_N]` | 视觉效果 | life, image, total_frames, scaleFrom/To, fadeIn/Out, xSpeed/ySpeed, soundToPlay |
| `[deathSpawn]` | 死亡时生成效果 | spawnEffects |
| `[canBuild_N]` | 工厂可生产单位 | name, pos |
| `[placementRule_N]` | 建筑放置规则 | searchTags, searchTeam, searchDistance, minCount/maxCount, blocksPlacement, cannotPlaceMessage |
| `[ai]` | AI 行为角色/优先级 | useAsBuilder/Transport/Attacker/Harvester, buildPriority, maxGlobal, maxEachBase, upgradedFrom |
| `[global_resource_X]` | 全局资源 | displayName, displayNameShort, displayColor, iconImage, displayPos, hidden |
| `[resource_X]` | 局部（单位）资源 | displayName, displayNameShort, displayColor |
| `[defineUnitMemory]` | 单位内存（自定义状态） | 任意键 + 数组 `abilities[5]` |
| `[template_X]` | 模板（复用） | 任意字段 + `@copyFromSection` |
| `[decal_N]` | 贴花（叠加视觉） | image, layer, order, isVisible, imageScale, xOffsetRelative, drawLineTo |

### 3.3 枚举值速查

- **movementType**：`LAND` / `WATER` / `AIR` / `HOVER`（两栖）/ `OVER_CLIFF` / `OVER_CLIFF_WATER`
- **drawType**（抛射体绘制）：`1`=精灵图（子弹），`2`=导弹（会转向/追踪），`4`=激光（配合 `instant:true`）
- **displayType**（行为）：`upgrade` / `attack` / `build` / `action`（默认）
- **layer**（贴花）：`shadow` / `beforeBody` / `afterBody` / `onTop` / `beforeUI`
- **searchTeam / onlyTeam**：`own` / `neutral` / `allyNotOwn` / `ally` / `enemy` / `any`（贴花另有 `notOwn`）
- **对比色**：`teamColoringMode:hueAdd`、`image_shadow:AUTO`（自动生成阴影）

### 3.4 逻辑与函数（`logic.html` + `global-functions.html`）

- **两种等价写法**：`self.hp < 100`（C 风格/嵌套函数）与 `self.hp(lessThan:100)`（`lessThan/greaterThan/equalTo/empty/full`）
- **运算符**：`== != < > <= >=`、`and or not`、`+ - * / %`
- **检查函数族**：
  - 资源：`hasResources(credits:1000, gold:10)`、`resource(type:"credits", greaterThan:1000)`
  - 位置：`isUnderwater / isFlying / isMoving / isAtTopSpeed / isInWater / isOverwater / isOverLiquid / isOverClift / isAtGroundHeight / isOverPassableTile(type:"WATER")`
  - 标签/队伍：`hasTags(includes:"infantry")`、`globalTeamTags`、`teamId`、`isOnNeutralTeam`、`isControlledByAI`
  - 统计：`kills`、`queueSize`、`transportingCount`、`numberOfAttachedUnits`
  - 时间：`timeAlive / lastConverted / customTimer / hasTakenDamage`（`laterThanSeconds` / `withinSeconds`）
  - 地图：`isInMap`、`game.mapWidth()`、`numberOfUnitsInTeam/EnemyTeam/NeutralTeam`
  - 引用：`hasParent`、`isAttacking`、`hasActiveWaypoint`、`transportingUnitWithTags`
- **数学/字符串**：`int max min squareRoot cos sin rnd distance distanceSquared distanceBetween direction createMarker`、`str substring length uppercase lowercase`
- **单位引用对象**：`thisActionTarget / eventSource / attachment / transporting / attacking / lastDamagedBy / parent / activeWaypointTarget`
- **动态文本**：`text:修复 (%{self.hp}/%{self.maxHp})`、`%{select(条件, "真显示", "假显示")}`
- **变量系统**：`@define`（局部）、`@global`（全局）、`${name}` 引用、`@copyFromSection` 复制模板节
- **内存读写**：`memory.experience`、`addResourcesWithLogic: experience += 10`

## 四、各章要点

**入门指南** — 文件结构、`mod-info.txt`、第一个单位完整示例、安装/测试/常见问题（单位不显示=图像路径；不能移动=movementType；不能攻击=[attack]；崩溃=INI 语法）、调试技巧（游戏调试模式、日志、逐步添加、备份）。

**单位创建** — `[core]`/`[graphics]`/`[movement]`/`[attack]`/`[turret_1]`/`[projectile_1]` 六段式模板；给出「基础坦克」「重型坦克」两个完整例子；高级属性提到 `generation_resources`、`[ai]`、`dustEffect/splastEffect`。

**建筑和工厂** — 建筑独有 `isBuilding:true`、`footprint:左,上,右,下`（不可通行区）、`constructionFootprint`（不可再建区）、`image_back`、`selfBuildRate`；工厂用 `[canBuild_N] name pos` 列出可生产单位；资源建筑/防御建筑/特殊功能建筑三类示例；放置规则简版。

**资源系统** — 内置资源 `credits / energy(需 maxenergy) / hp / shield / ammo`；标志资源 `addResources:setFlag=1,3` / `hasFlag(id:1)` / `unsetFlag`；全局资源 `[global_resource_X]`、局部资源 `[resource_X]`；生成 `generation_resources:credits:5,gold:1` + `generation_delay` + `generation_active` 条件；消耗 `resourceUsage`；转换行为 `price:gold=10` → `addResources:credits=1000`。

**AI 行为配置** — `[ai]` 角色开关、`buildPriority / noneInBaseExtraPriority / noneGlobalExtraPriority / recommendedInEachBaseNum`、AI 标签 `aiTags`、数量限制 `maxGlobal/maxEachBase`、升级 `ai_upgradePriority/upgradedFrom`；三例（建造者/采集车/突击坦克）。

**运输系统** — `maxTransportingUnits` / `transportSlotsNeeded`；限制 `transportUnitsRequireTag` / `...RequireMovementType` / `...BlockAirAndWaterUnits`；行为 `transportUnitsKeepBuiltUnits` / `...CanUnloadUnits` / `...AddUnloadOption` / `...UnloadDelayBetweenEachUnit`；安全 `transportUnitsKillOnDeath:if self.isOverLiquid()` / `...HealBy` / `...BlockOtherTransports`；中立运输 `whileNeutral*` / `convertToNeutralIfNotTransporting`。三例（运输车/运输船/运输直升机）。

**攻击系统** — 命中面 `canAttackFlying/Land/Underwater/NotTouchingWaterUnits`、`maxAttackRange`；目标标签 `canOnlyAttackUnitsWithTags/WithoutTags`；模式 `isMelee` / `meleeEngangementDistance` / `turretMultiTargeting` / `isFixedFiring`；行为 `stopTargetingAfterFiring` / `disablePassiveTargeting` / `showRangeUIGuide`；**伤害修正 mutator 系统**（`mutator_<名>_ifUnitWithTags` + `_directDamageMultiplier` + `_areaDamageMultiplier`，如穿甲/碾压建筑）；`shootDelayMultiplier/shootDamageMultiplier`。

**炮塔设置** — 位置/链接 `x,y,height,copyFrom,attachedTo,slave`；`canShoot` 与命中面；目标标签；**旋转控制** `idleDir / idleDirReversing / shouldResetTurret / idleSweepAngle / idleSweepDelay`；**射击控制** `delay / warmup / warmupCallDownRate / warmupNoReset / warmupShootDelayTransfer`；能量资源 `energyUsage / resourceUsage`；**范围限制** `limitingRange / limitingAngle / limitingMinRange / canAttackMaxAngle`；**拦截系统** `interceptProjectiles_withTags / _andTargetingGroundUnderDistance / _andUnderDistance / _andOverHeight` + `laserDefenceEnergyUse`；图形 `shoot_sound / shoot_flame / shoot_light`。

**抛射体** — 伤害 `directDamage / areaDamage / areaRadius / areaDamageNoFalloff / areaRadiusFromEdge`；运动 `speed / targetSpeed / targetSpeedAcceleration / ballistic / ballistic_height / targetGround / targetGroundSpread`；特殊 `instant / instantReuseLast / disableLeadTargeting / wobbleAmplitude / wobbleFrequency / pushForce`；**串联生成** `spawnProjectilesOnEndOfLife / OnExplode（支持 fragment*3 数量）/ OnCreate`；图形 `drawType / color / teamColorRatio / drawSize / frame / explodeEffect`；尾焰光照 `trailEffect / trailEffectRate / lightSize / lightColor / lightCastOnGround`；激光 `laserEffect / beamImage / beamImageOffsetRate`。四例（子弹/炮弹/导弹/激光）。

**全局功能** — 全局/局部资源；**内存系统** `[defineUnitMemory]` + `memory.xxx` + 数组；全局标签 `addGlobalTeamTags / removeGlobalTeamTags`；**模板系统** `[template_X]` + `@copyFromSection` + `@define/@global/${}`；**单位引用**；标记 marker；**全局函数**（距离、方向、随机、数学、字符串）。

## 五、质量观察（值得注意）

1. **地图制作整章空缺**：`map-creation.html` 正文只有「未制作」，且该文件内的 `<h1>` 标题误写为「放置规则」（疑似复制模板未改）。文档自述覆盖地图制作，实际只有模组部分。
2. **示例语法不一致**：`price` 写法混用冒号与等号——`price:credits:100`（8 处）与 `price:credits=100` / `price:gold=10`（5 处）。`resourceUsage` 同样是 `credits:5` 与 `credits=5` 两种。作为参考手册，这会误导读者。
3. **同一概念两种定义位置**：抛射体既可在单位文件内写 `[projectile_N]`，也可放在独立 `projectiles/*.ini`；文档两种都出现但未说明区别与优先级。
4. **文本风格高度模板化**：每章开头「本章节将详细介绍…」、结尾固定 5 条「注意事项」，内容较空泛（"合理设置…避免过高过低""测试…"），疑为批量生成后人工整理。首页「如果有问题请联系，错联删！」也提示内容来源可能是拼凑。
5. **HTML 未转义**：`logic.html` 的代码块里 `<` `>` 是字面量未转义（如 `>  # 大于`）。浏览器容错可正常显示，但自动化抽取/二次编辑时会被误当标签——本次抽取就踩了这个坑，需专门处理 `<pre>` 块。
6. **无版本适配说明**：仅 `resources.html` 提到「credits 若版本在 1.14 之前建议写全」，其余字段未标注适用的游戏版本，跨版本通用性存疑。
7. **字段名混用 camelCase / snake_case**：如 `total_frames`、`frame_width`、`image_wreak`（疑为 `wreck` 拼写）与 `animation_frameCount` 并列，容易记错。

## 六、附：原文提取方式

原始内容打包在 `resources.neu`，格式为：

```
[uint32 × 4 头部]  +  [JSON 索引：{"files":{路径:{size,offset,integrity}}}]
```

- 前 4 个 uint32 中的第 4 个 = JSON 头长度（本包为 7016），JSON 从偏移 16 开始。
- 数据区 = `16 + 头长度` 起的纯拼接；每个文件按索引里的 `offset/size` 切片。
- 索引是嵌套结构（`files` 里可再嵌 `files`），需递归展开。

本次已解包并转纯文本，产物在：

- `D:\Apps\rust-help\.tmp\extracted\` —— 原始 `resources/`（HTML/JS/图标/config）
- `D:\Apps\rust-help\.tmp\all_text.md` —— 20 章合并后的纯文本（约 11.5 万字符）
- `D:\Apps\rust-help\.tmp\extract_full.py` / `extract_text.py` —— 解包 / 转换脚本

> `.tmp` 及本文件若不再需要可直接删除，不影响应用运行。
