## 一、窗口外观（tauri.conf.json）

**文件:** `src-tauri/tauri.conf.json`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `app.windows[0].width` | `800` | 窗口宽度 (px) |
| `app.windows[0].height` | `1000` | 窗口高度 (px) |
| `app.windows[0].resizable` | `true` | 是否可拖拽调整大小 |
| `app.windows[0].decorations` | `false` | 系统标题栏 (`false`=无边框) |
| `app.windows[0].transparent` | `true` | 透明背景 |
| `app.windows[0].alwaysOnTop` | `true` | 始终置顶 |
| `app.windows[0].skipTaskbar` | `true` | 隐藏任务栏图标 |
| `app.windows[0].x` / `y` | `null` | 初始位置 (null=自动) |

## 二、角色配置（persona.config.ts）

**文件:** `src/persona.config.ts`

### 2.1 角色尺寸与位置 (`character`)

| 参数 | mao 值 | 说明 |
|------|--------|------|
| `scale` | `0.25` | 角色缩放 (值越大角色越大) |
| `posX` | `400` | 角色在画布中的 X 位置 |
| `posY` | `800` | 角色在画布中的 Y 位置 |
| `canvasWidth` | `800` | Pixi 画布宽度 |
| `canvasHeight` | `1000` | Pixi 画布高度 |

### 2.2 外观 (`appearance`)

| 参数 | mao 值 | 说明 |
|------|--------|------|
| `bgColor.r/g/b/a` | `20,20,30,0.35` | 窗口背景色 + 不透明度 |
| `borderRadius` | `8` | 窗口圆角半径 (px) |
| `chatBtnSize` | `32` | 💬 按钮尺寸 (px) |
| `chatBtnMargin` | `8` | 按钮距边缘距离 (px) |

### 2.3 呼吸动画 (`breathing`)

| 参数 | mao 值 | 说明 |
|------|--------|------|
| `periodMs` | `2000` | 呼吸周期 (ms)，值越大越慢 |
| `amplitude` | `0.02` | 摆动幅度 (弧度) |

### 2.4 口型同步 (`lipsync` + 元音系统)

**配置项 (`persona.config.ts` → `lipsync`)**:

| 参数 | mao 值 | 说明 |
|------|--------|------|
| `amplitude` | `1.0` | 参数倍率。1.0=原样，增大嘴更开 |
| `offset` | `0.0` | ParamA 偏移。+0.1=默认更张 |
| `speed` | `60` | (当前未使用，硬编码 `dt*35`) |
| `subFreq/subAmplitude/subOffset` | — | (当前未使用) |

**Mao 嘴部 paramIds (`persona.config.ts` → `paramIds`)**:

| 键 | Live2D ID | 含义 | 写入方式 |
|----|-----------|------|---------|
| `mouthOpen` | ParamA | A 元音，纵向张开 | beforeModelUpdate 连续值 |
| `mouthI` | ParamI | I 元音，嘴角横拉 | beforeModelUpdate 连续值 (×3 补偿) |
| `mouthU` | ParamU | U 元音，拢圆 | beforeModelUpdate 连续值 (×3 补偿) |
| `mouthE` | ParamE | E 元音，中开 | beforeModelUpdate 连续值 (×3 补偿) |
| `mouthO` | ParamO | O 元音，圆唇 | beforeModelUpdate 连续值 (×3 补偿) |
| `mouthUp` | ParamMouthUp | 上唇抬起 | 不写 (range 限制) |
| `mouthDown` | ParamMouthDown | 下唇/下颌下降 | beforeModelUpdate 连续值 |

**架构**：
- 口型参数在 Cubism4 `beforeModelUpdate` 事件 (step 10) 写入，在所有内部动画之后、顶点计算之前
- 韵母映射: pinyin-pro 逐字拆韵母 → 42 韵母 → 5 元音权重
- 能量格: 每 100ms 一帧，正弦波+噪声调幅
- 保真度: ParamA ~90%, ParamI/U/E/O ~90%, MouthDown 100%

| `idle` | (空) | `transparent` |

### 2.6 WebSocket (`websocket`)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `url` | `ws://127.0.0.1:9191/status` | WS 服务地址 |
| `reconnectDelayMs` | `3000` | 断线重连延迟 |
| `fallbackTimeoutMs` | `8000` | agent:end 后无 TTS 则回 idle |
| `hardTimeoutMs` | `30000` | 无论如何超时回 idle |
| `defaultTtsDurationMs` | `3000` | TTS 无 duration_ms 时的 fallback |

### 2.7 聊天面板 (`chat`)

| 参数 | 默认值 | 说明 |
|------|--------|------|

| `aiBubbleBg` | `rgba(255,255,255,0.12)` | AI 气泡背景 |
| `bubbleRadius` | `8` | 气泡圆角 (px) |
| `fontSize` | `11` | 对话字体大小 (px) |

## 三、Rust 后端（lib.rs）

**文件:** `src-tauri/src/lib.rs`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Python 路径 | 环境变量 `WAIFU_PYTHON`，fallback `python` | TTS / Hermes 调用 |
| Hermes 超时 | `120` 秒 | `send_message` 等待超时 |
| 临时音频目录 | `std::env::temp_dir()` | 跨平台临时目录 |
| ffplay 参数 | `-nodisp -autoexit -loglevel quiet` | 无窗口、播完退出、静默 |
| 能量分析采样率 | `8000` Hz | 口型能量提取用 |
| 能量分析窗口 | `800` 采样点 (100ms) | RMS 窗口 |

## 六、换 Live2D 模型

1. 下载模型放到 `public/live2d-models/{模型名}/`
2. 在 `src/persona.config.ts` 添加新的预设 (或修改现有预设的 `modelPath`)
3. 调整 `character.scale` / `posX` / `posY` / `canvasWidth` / `canvasHeight`
4. 若嘴部参数名不同，需检查 DiagPanel 中参数映射
5. 重启 `npx tauri dev`

## 七、所有配置入口速查

| 想改什么 | 改哪里 |
|---------|--------|
| 角色/外观/动画 | `src/persona.config.ts` → `ACTIVE_PERSONA` |
| LLM API | `llm_config.json` |
| 角色灵魂 | `SOUL.md` |
| 窗口置顶/尺寸 | `src-tauri/tauri.conf.json` |
| Python 路径 | 环境变量 `WAIFU_PYTHON` |
| TTS 音色 | `hermes-plugin/__init__.py` 或 `lib.rs` quick_speak |
| WS 端口/超时 | `src/persona.config.ts` → `websocket` 字段 |
