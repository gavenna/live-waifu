# waifu-agent 使用指南

> 桌面 Live2D 角色 + AI Agent — 从安装到客制化的完整指南

---

## 1. 环境准备

### 必需依赖

| 依赖 | 用途 | scoop 安装 |
|------|------|-----------|
| **Node.js** ≥ 18 | 前端构建 | `scoop install nodejs-lts` |
| **Rust** (MSVC) | Tauri 桌面后端 | `scoop install rustup-msvc` |
| **Python 3** | TTS 语音合成 (开发时) | `scoop install python` |

### Python 包

```bash
pip install edge-tts websockets faster-whisper  # 打包后自带，开发时手动装
```

### 项目依赖

```bash
cd waifu-agent
npm install          # Node 依赖（已配置 .npmrc 处理版本冲突）
```

## 2. 启动应用

### 三种构建模式

项目有 `dev` / `userdebug` / `user` 三种构建模式，由 `VITE_WAIFU_MODE` 环境变量控制：

| 模式 | 调试面板 | 日志量 | 用途 |
|------|:--:|:--:|------|
| `dev` | ✅ 全部 | 全量 | 研发自用 |
| `userdebug` | ❌ | 全量 | Beta 测试，UI 同正式版 |
| `user` | ❌ | 精简 | 正式发布 |

### 常用命令速查

| 场景 | 命令 |
|------|------|
| 🔧 调试 (dev) | `npm run tauri:dev` |
| 🔧 调试 (user 模式) | `npm run tauri:dev:user` |
| 🔧 调试 (userdebug) | `npm run tauri:dev:userdebug` |
| 📦 打包正式版 | `npm run tauri:build` |
| 📦 打包 Beta 版 | `npm run tauri:build:userdebug` |
| 🌐 仅前端 | `npm run dev` |
| 🔍 TS 类型检查 | `./node_modules/.bin/tsc --noEmit` |
| 🦀 Rust 检查 | `cd src-tauri && cargo check` |

> **提示**: 调试时加 user 模式可预览正式版 UI 效果（无调试面板），但能看到完整日志。正式版打包时日志也会精简。

### 开发模式

```bash
# 方式 1: npm scripts（推荐）
npm run tauri:dev                         # dev 模式，全部面板可见

# 方式 2: 手动控制环境变量（bash / PowerShell）
export VITE_WAIFU_MODE=user && npx tauri dev   # bash: 以 user 模式调试

# 方式 3: 分步启动（方便排查前端问题）
npm run dev                              # 终端1: Vite 前端 → localhost:1420
npx tauri dev                            # 终端2: Tauri 桌面窗口
```

首次编译 Rust 后端需要几分钟，后续启动很快。

### 生产构建

```bash
npm run tauri:build                       # 正式发布 (user 模式)
npm run tauri:build:userdebug             # Beta 测试版
# 输出: src-tauri/target/release/bundle/msi/
```

## 3. 配置 LLM（必须）

编辑项目根目录的 `llm_config.json`，或者在设置面板中直接修改：

```json
{
  "api_url": "https://api.deepseek.com/v1/chat/completions",
  "api_key": "你的API密钥",
  "model": "deepseek-v4-flash",
  "timeout_secs": 30
}
```

支持的 API：
- DeepSeek（默认）
- OpenAI
- 任何 OpenAI 兼容 API（Ollama、vLLM 等）

## 4. 设置面板 ⚙

点击窗口底部的 **⚙ 按钮** 打开设置面板。所有修改**即时生效**，2 秒后自动保存到 `~/.waifu-agent/settings.json`。

### 4.1 角色切换

下拉选择 persona，7 套预设可选：

| 预设 | 模型 | 风格 |
|------|------|------|
| `mao` **(默认)** | Mao | 大尺寸，近距离 |
| `default` | Haru Greeter | 标准比例，通用 |
| `jarvis` | Haru Greeter | 小尺寸，助理风 |
| `yuanqi` | Haru Greeter | 大画布，元气风 |
| `sage` | Haru Greeter | 小尺寸，智者风 |
| `healer` | Haru Greeter | 柔和配色，治愈风 |
| `lipsyncTest` | Haru Greeter | 口型测试用 |

切换后自动重载 Live2D 模型。

### 4.2 角色尺寸

| 参数 | 说明 | 范围 |
|------|------|------|
| 缩放 | 角色显示大小 | 0.01 - 2 |
| X/Y 位置 | 角色在窗口中的位置 | 0 - 2000 |
| Canvas 宽/高 | Pixi 渲染画布尺寸 | 100 - 2000 |

### 4.3 外观

| 参数 | 说明 | 范围 |
|------|------|------|
| R/G/B | 窗口背景色 RGB | 0 - 255 |
| A | 窗口不透明度 | 0 - 1 |
| 圆角 | 窗口圆角半径 (px) | 0 - 40 |
| 按钮大小 | 💬/⚙ 按钮尺寸 | 20 - 60 |
| 按钮边距 | 按钮距边缘距离 | 2 - 40 |

### 4.4 呼吸动画

| 参数 | 说明 | 范围 |
|------|------|------|
| 周期 | 呼吸一次的时间 (ms) | 500 - 10000 |
| 幅度 | 角色摆动弧度 | 0.001 - 0.2 |

### 4.5 口型同步

| 参数 | 说明 | 范围 |
|------|------|------|
| 速度 | 嘴动振荡速度 | 10 - 200 |
| 幅度 | 基础张嘴大小 | 0 - 1 |
| 偏移 | 基础张口偏移 | 0 - 1 |
| 子频率/幅度/偏移 | 次级抖动参数 | 0 - 10 / 0 - 1 / 0 - 1 |

### 4.6 LLM API

- **API URL**: 兼容 OpenAI 的 endpoint
- **API Key**: 密钥（可点 ○ 切换显示/隐藏）
- **Model**: 模型名称
- **超时**: HTTP 请求超时秒数

修改后写入 `llm_config.json`，下次对话生效。

### 4.7 窗口

- **始终置顶**: 窗口悬浮在所有窗口之上
- **隐藏任务栏**: 不在任务栏显示图标

立即生效，无需重启。

### 4.8 WebSocket

- **URL**: Agent 状态服务地址（默认 `ws://127.0.0.1:9191/status`）
- **重连延迟**: 断线后等待多少 ms 重连

## 5. 聊天

点击 **💬 按钮** 打开聊天面板。

### 5.1 双模式

| 模式 | 后端 | 适合 |
|------|------|------|
| ⚡ 快 | DeepSeek / OpenAI API | 日常对话、角色扮演 |
| 🧠 深 | Hermes Agent CLI | 复杂任务、工具调用、多步推理 |

点击面板左上角按钮切换。

### 5.2 输入方式

- **直接输入**: 打字后 Enter 发送
- **拼音模式**: 点击 **拼** 按钮开启，输入拼音显示候选字，按数字选字

### 5.3 TTS 语音

- 快速模式: 自动通过 edge-tts (zh-CN-XiaoxiaoNeural) 合成语音
- 深度模式: Hermes Plugin 自动生成 TTS 并通过 WebSocket 推送

**3 种场景，12 张贴图：**

| 场景 | 贴图 | 文案 | 触发时机 |
|------|------|------|---------|
| **日常** 🐱 | daily-smug | "拿捏了😼" | AI 说了俏皮话后 |
| | daily-eyeroll | "你开心就好🙄" | 用户重复问题或说教 |
| | daily-confused | "啊？你说啥🤨" | 用户说意想不到的话 |

| **亲密** 💕 | intimate-flustered | "犯规！！！😳💕" | 用户说了甜话/表白 |
| | intimate-hug | "抱抱🥺🤲" | 甜蜜互动后想要拥抱 |

## 6. 角色灵魂 SOUL.md

编辑项目根目录的 `SOUL.md`，定义角色的个性、语气、与主人的关系。

快速模式下自动作为 system prompt 注入（前 800 字符）。例如：

```markdown
你是 waifu，一个温柔体贴的桌面伙伴。主人叫 Kevin。
你说话简洁亲和，用中文，不超过 3 句。
喜欢用 "主人" 称呼对方。偶尔会关心主人有没有好好休息。
```

## 6. 角色记忆（v0.8+ 自动记忆系统）

waifu-agent 内置基于 N.E.K.O. 的记忆子系统，**对话后自动提取事实，无需手动说"记住"**。

### 工作原理

```
每轮对话结束 → LLM 自动提取 1-3 条事实 → 存储 → 下次聊天时语义召回相关记忆
```

角色会逐渐记住你的习惯、偏好、经历——聊得越多，记得越多。

### 数据存储

所有记忆存在 `%APPDATA%\com.waifu-agent.app\memory\mao\`：

```
facts.json        # 自动提取的事实（带重要性评分 1-10）
persona.json      # 角色人格数据
recent.json       # 近期对话记录
time_indexed.db   # 时间索引数据库
```

### 记忆驱动的人格

角色的 system prompt 会自动注入：
- **相关记忆**：根据当前话题语义召回最相关的几条记忆
- **人格数据**：长期积累的角色对主人的认知

### 兼容旧版 MEMORY.md

如果记忆系统未初始化（Python 环境不完整），waifu 自动回退到传统 `MEMORY.md` 文件模式。

## 9. 深度模式（Hermes）

深度模式需要额外安装 Hermes Agent：

1. 安装 Hermes Agent 并配置
2. 将 `hermes-plugin/` 复制到 Hermes 的 plugins 目录
3. 将 `hermes-hook/` 配置到 Hermes Gateway
4. 设置环境变量 `WAIFU_HERMES_PYTHON` 指向 Hermes 的 Python（可选，默认用系统 python）

Hermes 启动后会自动在 9191 端口提供 WebSocket 服务，桌面应用连接后即可接收 agent 状态事件。

## 10. 许可验证

### 10.1 工作机制

支付走**爱发电**，验证走**激活码**。完整流程：

```
爱发电赞助 → 管理员生成激活码 → 私信发你
打开 App → 输入激活码 → 自动绑定设备 → 永久使用
```

- 激活码是一次性的，绑定后即失效
- 每码限绑 **1 台设备**（换电脑需联系管理员解绑）
- 本地 token 缓存 30 天，离线也能用
- 30 天后 token 过期，需重新激活（续费后拿新码）

### 10.2 用户侧

首次打开 App 会看到激活码输入界面。填入管理员给你的激活码（格式: `WA-PRO-XXXX...`），点激活即可。

激活成功后自动进入主界面，后续启动无需再次输入。

### 10.3 换设备

联系管理员解绑旧设备 → 在新电脑上输入激活码重新激活。激活码在有效期内可重复用于新设备绑定。

### 10.4 管理员操作

详见 [[许可运维指南.md]]：
- `gen-key.ts` 生成激活码（支持 tier/有效期/设备数配置）
- `admin.html` 管理后台：查用户、解绑设备、封禁/解封
- API 文档：10 个 endpoint，部署在 Vercel + Neon

## 11. 故障排除

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| npm install 失败 | pixi-live2d-display 版本冲突 | 已配置 `.npmrc`，重新 `npm install` |
| tauri dev 窗口不出现 | Vite 端口被占用 | 杀掉 1420 端口进程 |
| 聊天报错 | llm_config.json 未配置 | 检查 API URL 和 Key |
| TTS 没声音 | Python/edge-tts 不可用, 已兜底系统语音 | 开发: `pip install edge-tts`; 打包: 跑 setup-python-embed.ps1 |
| TTS 音质差 | 走了 Web Speech 兜底 | 确保 Python edge-tts 可用 |
| 窗口无法拖拽 | 需要按住透明区域 | 窗口有 0.35 不透明度的背景，按住即可拖拽 |
| 设置没保存 | 权限问题 | 检查 `~/.waifu-agent/` 目录是否可写 |
