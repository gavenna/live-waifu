# 模型实验室 & Live2D 功能指南

> mao 模型完整功能清单，以及如何使用实验室窗口测试新模型。

## 实验室窗口

### 打开方式

主窗口左上角 **🧪 实验室** 按钮，弹出独立窗口（900×600）。

### 三个功能页

| 页签 | 内容 | 操作 |
|------|------|------|
| 🎬 **动作** | 所有 Motion 按组列出 | 点击播放/停止，绿色按钮自动循环（3s 切换） |
| 🎭 **表情** | 所有 Expression 网格 | 点击切换，带中文描述 |
| 🎛 **参数** | 全部 Live2D Parameter | 滑块实时调参，数值框直接输入，搜索过滤，一键重置默认值 |

右侧 300×400 预览画布实时反映所有改动。

| 索引 | 文件 | 时长 | 循环 | 说明 |
|------|------|------|------|------|
| 0 | `mtn_02` | 3.47s | 是 | 轻触身体 |
| 1 | `mtn_03` | 3.5s | 是 | 点头/身体前倾 |
| 2 | `mtn_04` | ~3.5s | 是 | 身体侧倾 |
| 3 | `special_01` | 7.8s | 是 | 魔法动画（手臂/特效/爱心/光环） |

#### 播放 API

```typescript
// 优先级: IDLE(1) / NORMAL(2) / FORCE(3)
model.motion("Idle", 0);        // 播放 Idle[0]
model.motion("TapBody", void 0); // 随机一个 TapBody
model.motion("TapBody", 3, 3);  // 强制播放 special_01
```

### 🤖 自动系统

| 系统 | 来源 | 说明 |
|------|------|------|
| **EyeBlink** | model3.json Groups | 自动眨眼，驱动 ParamEyeLOpen/ROpen。**不要手动设这两个参数，会覆盖内置系统** |
| **LipSync** | model3.json Groups | 口型同步组，指定 ParamA 为口型参数。**这个参数叠加在 motion 之上，不会被覆盖** |
| **Physics** | Mao.physics3.json | 头发、衣摆物理模拟 |
| **Pose** | Mao.pose3.json | 姿态修正 |
| **Breath** | ParamBreath 参数 | 呼吸动画，由内置系统自动驱动 |

### Cubism 分层模型（重要）

```
Layer 1: Motion 层   — 身体/面部/手臂, 每帧由 motion 更新
Layer 2: LipSync 层  — 口型参数 (ParamA), 叠加在 motion 之上
Layer 3: EyeBlink 层 — 自动眨眼, 独立系统
Layer 4: Expression   — 表情快照, 可以和 motion 并存
```

**程序只能安全地操作 LipSync 层**。手动设身体参数（如 ParamBodyAngleZ）会被 motion 的下一帧覆盖。身体动作完全交给 motion 系统（Idle/TapBody）。

## 换新模型的流程

1. 下载模型文件夹，放到 `public/live2d-models/{model-name}/`
2. 打开 🧪 实验室窗口，确认模型能加载
3. 在 🎛 参数页搜索 `Mouth`，找到口型相关参数
4. 在 🎬 动作页查看所有 Motion 组和时长
5. 在 🎭 表情页确认所有 Expression
6. 在 `persona.config.ts` 添加新预设，填入正确的 `paramIds`
7. 在设置窗口切换到新预设测试

---

## 已知限制

- 实验室窗口加载模型需要几秒（WebAssembly 初始化）
- 部分魔法特效参数（Rabbit, Heart, Explosion 等）的正常表现依赖 motions 上下文，单独调参可能看不出效果
- 换模型时必须在 persona.config.ts 正确填写 `paramIds`，否则动画系统不好使
