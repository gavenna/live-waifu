## React inline style `background` 简写打断 CSS 动画

**发现日期**：2026-07-11

**症状**：同一个视觉效果，用 CSS class 渲染正常，换成 React inline style 就不对——动画卡顿、不同步、或看起来"不一样"。

**根因**：`background` 是 CSS 简写属性。React inline style 中每次变化（如从 `"transparent"` 切到 `"linear-gradient(...)"`）会重置所有 background 子属性，包括 `background-position`。如果同元素上有 `@keyframes` 动画在操控 `background-position`，动画会被打断。

**案例**：致谢画面 shimmer 扫光效果——inline style 动态切换 `background` 导致各行 shimmer 动画相位错乱。改为 CSS class 解决。

**修复**：
- 不变的 CSS 属性放 CSS class，inline style 只保留动态属性
- 或拆简写为子属性：`background-image` + `background-size` 代替 `background`

**同类简写属性**：`font`、`border`、`margin`、`padding`、`animation`、`transition`、`flex`、`grid`——都有相同风险。

## 视觉特效开发：先建调参面板

**发现日期**：2026-07-11

改代码 → 编译 → 启动 → 观察的循环一次几分钟。直接在实验室面板加几个滑块实时调参，一秒出结果。

**原则**：任何需要反复微调的视觉参数（颜色、透明度、速度、渐变范围），先花 10 分钟建个面板。
