# 开机流程

> waifu-agent 从进程启动到完全就绪的完整初始化链路。
> 最后更新: 2026-07-02 15:30

---

## 总览

```
Rust main() → setup() → 窗口显示
                          ↓
React main.tsx → App → MainWindow mount
                          ├→ 数据加载 (settings/history/auth/memory)
                          ├→ PIXI + Live2D 初始化
                          └→ StartupSequence 启动动画 (4 阶段)
                                                        ↓
                                              handleStartupComplete()
                                              应用完全就绪
```

**6 个阶段，约 8-14 秒**，主导因素是 Live2D 模型加载 + 启动动画节奏。

---

## 阶段 0: 进程启动 (Rust)

`src-tauri/src/main.rs` → `lib.rs::run()`

- 注册 Tauri 插件 (`tauri_plugin_opener`, `tauri_plugin_autostart`)
- 注册全部 Tauri command（约 50 个，见 `invoke_handler![]`）
- 创建 WebView 窗口：600×800，透明无框，`visible: false`（初始隐藏）

---

## 阶段 1: Rust `setup()` 回调

窗口创建后、前端加载前，同步执行。`src-tauri/src/lib.rs` 的 `.setup()` 闭包。

| 顺序 | 操作 | 说明 |
|:--:|------|------|
| 1 | 日志初始化 | 创建 app data dir，轮转 `waifu-agent.log` → `waifu-agent.prev.log` |
| 2 | STT daemon 预加载 | 后台线程启动 faster-whisper，预热语音识别模型 |
| 3 | 趋势新闻抓取 | 异步拉知乎热榜 top5，之后每 2 小时刷新 |
| 4 | TTS daemon 预加载 | 后台线程启动 edge-tts Python 进程 |
| 5 | 恢复窗口位置+尺寸 | 读 `window_pos.json` + `settings.json`；无记录则居中 → `window.show()` |
| 6 | 系统托盘 | 托盘图标 + 右键菜单 (Show/Quit) + 双击显示窗口 |
| 7 | 拦截关闭 | 点 X → 保存位置 → `hide()`，不退进程 |

---

## 阶段 2: 前端入口 (React)

`src/main.tsx`:

1. **劫持 console** — `console.log/warn/error` 额外调用 `invoke("frontend_log")` 写入 Rust 日志
2. `ReactDOM.render(<App />)` — 挂载根组件

`src/App.tsx` → `App()`:

- 解析 `URLSearchParams('view')`
- 主窗口无 query → 渲染 `<MainWindow />`
- 其他 query 路由: `?view=settings` → SettingsWindow, `?view=chat` → ChatWindow

---

## 阶段 3: MainWindow 挂载 — 数据并行加载

`MainWindow()` mount 时，以下操作并行发起：

| 操作 | 调用链 | 说明 |
|------|--------|------|
| 启动动画层 | `startupPhase = "running"` | StartupSequence 组件渲染为全屏覆盖层 |
| 加载设置 | `loadSettingsWithLlm()` → `invoke("load_settings")` + `mergeWithDefaults()` | 合并 `settings.json` 和 `llm_config.json` |
| 加载历史 | `invoke("load_history")` | 最近 20 条对话，写入 `chatMessages` state |
| 记忆反思 | `distill_memory` (fire-and-forget) | LLM 反思近期对话，更新记忆 |
| 记忆系统 | `memory_configure` (fire-and-forget) | N.E.K.O. 记忆系统 Python 子进程初始化 |
| 用户/记忆文件 | `invoke("load_user_md")` / `invoke("load_memory_md")` | 读取 `USER.md` 和 `MEMORY.md` |
| 许可验证 | `load_auth_token` → 机器码校验 → Gitee → Vercel fallback | 三步 fallback 链，最终 `authState` 到位 |
| 画像检查 | `portrait_exists` + `has_knowledge_base` | 许可通过后触发，决定是否显示 onboarding |

---

## 阶段 4: PIXI + Live2D 初始化

| 顺序 | 操作 | 关键点 |
|:--:|------|--------|
| 1 | `new PIXI.Application()` | 透明背景、自适应分辨率 |
| 2 | 注册主 ticker | 此时 `suppressTickerRef=true`，ticker 只更新帧时间不做动画 |
| 3 | `loadModel()` → `Live2DModel.from()` | 加载 Cubism 4 模型文件，`model.alpha=0` 隐藏 |
| 4 | 订阅 `beforeModelUpdate` | 口型参数写入点（在物理/姿态之后，保证不被覆盖） |

---

## 阶段 5: 启动动画 (StartupSequence)

`src/App.tsx` 中的 `StartupSequence` 组件，4 个子阶段：

| Phase | 名称 | 内容 |
|:-----:|------|------|
| 0-1 | 终端打字机 | 逐字显示 boot lines + 闪烁光标 `_` |
| 2 | 粒子溶解 | 终端淡出 + PIXI 粒子汇聚到角色位置 |
| 3 | 模型唤醒 | `model.alpha` 0→1 + 闭眼睁眼 "眨眼醒来" |
| 4 | 问候语 | 角色 body tap 动作 + 表情 + TTS 语音问候 |

用户可以随时跳过：组件监听点击/按键，直接调用 `finish()`。

---

## 阶段 6: `handleStartupComplete()` — 激活

```tsx
startupPhaseRef.current = "done"
setStartupPhase("done")        // StartupSequence 从 DOM 移除
suppressTickerRef.current = false  // ticker 开始呼吸/口型/表情动画
document.body.style.background = "transparent"
if (model.alpha ≈ 0) model.alpha = 1  // 兜底
```

此后应用完全就绪：
- PIXI ticker 正式运行（呼吸、idle 动作、表情管理）
- 键盘监听活跃（空格按住说话）
- 聊天中继监听活跃（`chat-send` 事件）
- 托盘就绪（双击显示、右键菜单）
- 后台 daemon 持续运行（STT 模型常驻、趋势 2h 刷新）

---

## 完整时间线

| 时间 | 层 | 事件 |
|------|-----|------|
| 0ms | Rust | `main()` → `run()` |
| ~5ms | Rust | 窗口创建 (隐藏), `setup()` 启动所有 daemon |
| ~10ms | Rust | 恢复位置 → `window.show()` → 托盘就绪 |
| ~50ms | React | `main.tsx` → `<App>` → `<MainWindow>` |
| ~60ms | React | `startupPhase="running"`, StartupSequence 覆盖层渲染 |
| ~70ms | React | settings / history / auth / memory / userMd 并行发起 |
| ~100ms | React | PIXI app 创建, Live2D 模型开始加载 |
| ~200-800ms | React | 模型加载完成 (`alpha=0` 隐藏) |
| ~4-8s | 动画 | 终端打字机 → 粒子溶解 |
| ~5-9s | 动画 | 模型唤醒 (淡入 + 眨眼) |
| ~6-10s | 动画 | 问候语 TTS + 表情 |
| ~8-14s | 动画 | `handleStartupComplete()` → **完全就绪** |
