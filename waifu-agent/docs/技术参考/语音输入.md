# waifu-agent 语音输入 (STT) 设计方案

> 本地离线语音识别 — faster-whisper 嵌入式 Python，跟现有 edge-tts 同款模式。
> 最后更新: 2026-05-24

---

## 一句话

**让角色能听懂你说话** — 按住 🎤 按钮说话 → 录音 → faster-whisper 离线转文字 → 发给 LLM。

---

## 数据流

```
┌──────────────────────────────────────────────────────────┐
│  前端 (React)                                             │
│                                                          │
│  用户按住 🎤 说话 → MediaRecorder 录音 → WebM Blob        │
│       ↓                                                  │
│  invoke("stt_transcribe", { audio: base64WebM })         │
│       ↓ Tauri IPC                                        │
│                                                          │
│  Rust 后端 (lib.rs)                                       │
│                                                          │
│  stt_transcribe()                                         │
│       ↓ base64解码 → 临时WAV                              │
│       ↓ subprocess run ↓                                  │
│  嵌入式 Python / scripts/stt.py                           │
│       │  faster-whisper (base模型, CPU int8)               │
│       │  首次启动自动下载模型 ~150MB                        │
│       ↓ stdout: 文字                                      │
│       ↓                                                  │
│  返回前端 → 文字填入输入框 / 直接发送给 LLM                │
└──────────────────────────────────────────────────────────┘
```

### 跟现有 TTS 架构完全对称

TTS 链路：
```
前端(说话) → invoke("edge_tts") → Rust → Python edge-tts → base64 MP3 → Web Audio
```

STT 链路：
```
前端(🎤) → invoke("stt_transcribe") → Rust → Python faster-whisper → 文字 → LLM
```

都是**前端 → Rust invoke → Python 子进程**，同一套模式。

## 参考源: Hermes Agent 源码

Hermes 的 STT 实现，可以翻来参考细节：

| Hermes 源文件 | 功能 | 对 waifu-agent 的参考价值 |
|------|------|---------------------------|
| `tools/transcription_tools.py` — `_transcribe_local()` | faster-whisper 转录，CUDA fallback，模型管理 | 直接抄，改输出从 dict → stdout |
| `tools/voice_mode.py` | 录音器 + VAD | 前端用 MediaRecorder 替代 |
| `hermes_cli/voice.py` | Push-to-talk / VAD 循环 | 不用参考（waifu 是桌面按钮模式） |

### Hermes faster-whisper 核心逻辑

```python
# transcription_tools.py _transcribe_local() 的简化版本:
from faster_whisper import WhisperModel

model = WhisperModel("base", device="cpu", compute_type="int8")
segments, info = model.transcribe("/path/to/audio.wav", beam_size=5)
transcript = " ".join(segment.text.strip() for segment in segments)
print(transcript)  # stdout = 结果
```

关键参数：
- `model = "base"` — 平衡体积(~150MB)和准确率
- `device = "cpu"` — 兼容所有 Windows 机器
- `compute_type = "int8"` — 在 CPU 上最快的量化
- `beam_size = 5` — 解码波束宽度
- `language = "zh"` — 强制中文模式（更准）

## Python 端实现

### `scripts/stt.py` — faster-whisper 封装

跟 `edge-tts` 调用方式一致：接收参数 → 干活 → 结果打 stdout。

```python
#!/usr/bin/env python3
"""STT: faster-whisper 本地语音转文字。

Usage:
    python scripts/stt.py <input_audio.wav> [--model base] [--language zh]

Output:
    stdout → 转录文字
    stderr → 日志/错误信息
"""
import argparse, sys, logging

logging.basicConfig(level=logging.WARNING, stream=sys.stderr)

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("input_wav")
    parser.add_argument("--model", default="base")
    parser.add_argument("--language", default="zh")  # None = auto-detect
    args = parser.parse_args()

    from faster_whisper import WhisperModel

    model = WhisperModel(args.model, device="cpu", compute_type="int8")
    segments, _ = model.transcribe(
        args.input_wav,
        language=args.language or None,
        beam_size=5,
    )
    transcript = " ".join(s.text.strip() for s in segments)
    print(transcript, end="")

if __name__ == "__main__":
    main()
```

**注意事项：**
- `language` 传 `"zh"` 强制中文模式（更准更短），传 `None` = 自动检测
- 模型下载：首次运行自动从 HuggingFace 拉取 `~/.cache/faster-whisper/base/`
- 打包时模型可以预下载后跟 installer 一起分发（避免用户安装时下载 ~150MB）

### `scripts/setup-python-embed.ps1` 修改

加一行：

## Rust 端实现

### 新增 `src-tauri/src/stt.rs`

```rust
// stt.rs — faster-whisper transcription via embedded Python
use std::path::PathBuf;
use std::process::Command;

/// Transcribe audio file to text using faster-whisper (local, offline).
///
/// Calls `python scripts/stt.py <wav_path>` and returns stdout text.
pub fn transcribe(wav_path: &str, python_path: &str, stt_script: &PathBuf) -> Result<String, String> {
    let output = Command::new(python_path)
        .arg(stt_script)
        .arg(wav_path)
        .arg("--language")
        .arg("zh")
        .output()
        .map_err(|e| format!("stt subprocess failed: {e}"))?;

    if !output.status.success() {
        let err = String::from_utf8_lossy(&output.stderr);
        return Err(format!("stt failed: {err}"));
    }

    let text = String::from_utf8_lossy(&output.stdout).trim().to_string();
    if text.is_empty() {
        return Err("stt returned empty transcript".into());
    }
    Ok(text)
}
```

### `lib.rs` 新增 command

```rust
#[tauri::command]
async fn stt_transcribe(app: tauri::AppHandle, audio_base64: String) -> Result<String, String> {
    // 1. 解码 base64 → 临时 WAV 文件
    use std::io::Write;
    let bytes = base64::Engine::decode(
        &base64::engine::general_purpose::STANDARD,
        &audio_base64,
    ).map_err(|e| format!("base64 decode: {e}"))?;

    let tmp_dir = std::env::temp_dir().join("waifu-stt");
    std::fs::create_dir_all(&tmp_dir).map_err(|e| format!("mkdir: {e}"))?;
    let wav_path = tmp_dir.join(format!("input_{}.wav", std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH).unwrap().as_millis()));

    // 前端录的是 webm，需要 ffmpeg 转 wav
    let webm_path = wav_path.with_extension("webm");
    std::fs::write(&webm_path, &bytes).map_err(|e| format!("write: {e}"))?;

    // ffmpeg -y -i input.webm -ar 16000 -ac 1 -sample_fmt s16 output.wav
    let ffmpeg_status = std::process::Command::new("ffmpeg")
        .args(["-y", "-i"])
        .arg(&webm_path)
        .args(["-ar", "16000", "-ac", "1", "-sample_fmt", "s16"])
        .arg(&wav_path)
        .stdout(std::process::Stdio::null())
        .stderr(std::process::Stdio::null())
        .status()
        .map_err(|e| format!("ffmpeg: {e}"))?;

    if !ffmpeg_status.success() {
        let _ = std::fs::remove_file(&webm_path);
        return Err("ffmpeg conversion failed".into());
    }

    // 2. 调 Python stt.py
    let python = std::env::var("WAIFU_PYTHON").unwrap_or_else(|_| "python".into());
    let resource_dir = app.path().resource_dir()
        .map_err(|e| format!("resource dir: {e}"))?;
    let stt_script = resource_dir.join("scripts").join("stt.py");

    let result = stt::transcribe(
        &wav_path.to_string_lossy(),
        &python,
        &stt_script,
    );

    // 3. 清理临时文件
    let _ = std::fs::remove_file(&webm_path);
    let _ = std::fs::remove_file(&wav_path);

    result
}
```

**注意：** 前端传过来的是 WebM，需要 ffmpeg 转成 16kHz mono WAV 才能喂给 faster-whisper。Hermes 也是这么干的（`voice_mode.py` 里的 `_prepare_local_audio()`）。这个 ffmpeg 转换是 STT 独有的，TTS 那边不需要。

## 前端实现

### `src/hooks/useStt.ts`

```tsx
// src/hooks/useStt.ts — 录音 + 转录
import { invoke } from '@tauri-apps/api/core';
import { useRef, useState, useCallback } from 'react';

export function useStt() {
  const mediaRecorderRef = useRef<MediaRecorder | null>(null);
  const chunksRef = useRef<Blob[]>([]);
  const [isRecording, setIsRecording] = useState(false);
  const [isTranscribing, setIsTranscribing] = useState(false);

  const startRecording = useCallback(async () => {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    // WebM 在 WebView2 中支持良好，ffmpeg 能转
    const recorder = new MediaRecorder(stream, { mimeType: 'audio/webm' });
    chunksRef.current = [];
    recorder.ondataavailable = (e) => chunksRef.current.push(e.data);
    recorder.start();
    mediaRecorderRef.current = recorder;
    setIsRecording(true);
  }, []);

  const stopRecording = useCallback(async (): Promise<string | null> => {
    return new Promise((resolve) => {
      const recorder = mediaRecorderRef.current;
      const stream = recorder?.stream;
      if (!recorder) { resolve(null); return; }

      recorder.onstop = async () => {
        setIsRecording(false);
        setIsTranscribing(true);

        try {
          const blob = new Blob(chunksRef.current, { type: 'audio/webm' });
          const base64 = await blobToBase64(blob);
          const text = await invoke<string>('stt_transcribe', { audioBase64: base64 });
          resolve(text);
        } catch (e) {
          console.error('stt_transcribe failed:', e);
          resolve(null);
        } finally {
          setIsTranscribing(false);
        }
      };

      recorder.stop();
      // 释放麦克风
      stream?.getTracks().forEach(t => t.stop());
    });
  }, []);

  const cancelRecording = useCallback(() => {
    const recorder = mediaRecorderRef.current;
    const stream = recorder?.stream;
    if (recorder && recorder.state !== 'inactive') {
      recorder.stream.getTracks().forEach(t => t.stop());
      recorder.stop();
    }
    setIsRecording(false);
    setIsTranscribing(false);
  }, []);

  return { isRecording, isTranscribing, startRecording, stopRecording, cancelRecording };
}

function blobToBase64(blob: Blob): Promise<string> {
  return new Promise((resolve) => {
    const reader = new FileReader();
    reader.onloadend = () => {
      const result = reader.result as string;
      resolve(result.split(',')[1]); // 去掉 data:...;base64, 前缀
    };
    reader.readAsDataURL(blob);
  });
}
```

### `src/components/SttButton.tsx`

```tsx
// src/components/SttButton.tsx — 🎤 按钮
import { useStt } from '../hooks/useStt';

interface Props {
  onResult: (text: string) => void;  // 转录结果回调
}

export function SttButton({ onResult }: Props) {
  const { isRecording, isTranscribing, startRecording, stopRecording, cancelRecording } = useStt();

  const handleMouseDown = async () => {
    try {
      await startRecording();
    } catch (e) {
      console.error('mic access denied:', e);
    }
  };

  const handleMouseUp = async () => {
    const text = await stopRecording();
    if (text) onResult(text);
  };

  const handleMouseLeave = () => {
    if (isRecording) cancelRecording();
  };

  const icon = isTranscribing ? '⏳' : isRecording ? '🔴' : '🎤';
  const className = `stt-btn ${isRecording ? 'recording' : ''}`;

  return (
    <button
      className={className}
      onMouseDown={handleMouseDown}
      onMouseUp={handleMouseUp}
      onMouseLeave={handleMouseLeave}
      disabled={isTranscribing}
      title="按住说话"
    >
      {icon}
    </button>
  );
}
```

## 打包方案

跟 edge-tts 完全一致，改 `setup-python-embed.ps1`：

```powershell
# 在 edge-tts 安装后面追加
Write-Host "Installing faster-whisper..." -ForegroundColor Cyan
Run-Python -Args "-m pip install faster-whisper"
```

**模型预下载（可选但推荐）：** 安装脚本里加一步预下载 base 模型：

```powershell
# 预下载 faster-whisper base 模型（~150MB，安装时下载）
Write-Host "Downloading whisper model (base, ~150MB)..." -ForegroundColor Cyan
Run-Python -Args "-c ""from faster_whisper import WhisperModel; WhisperModel('base', device='cpu', compute_type='int8')"""
```

这样用户装完立刻能用，不用等首次运行时才下载 150MB 模型。

**安装包体积变化：**
- 之前（TTS only）: ~55MB（exe）+ ~50MB（Python embed + edge-tts）
- 加 STT: +150MB（模型文件）+ 少量 Python 依赖
- 总计: **~260MB** 左右

## 参考: Hermes faster-whisper 关键细节

### 模型大小选择

| 模型 | 磁盘 | 内存 | CPU 速度 | 准确率 | 推荐？ |
|------|------|------|---------|--------|-------|
| `tiny` | ~75MB | ~1GB | ~2x 实时 | 低 | ❌ 中文差 |
| `base` | ~150MB | ~1.5GB | ~1x 实时 | 中 | ✅ **首选** |
| `small` | ~460MB | ~2GB | ~0.5x 实时 | 高 | 可选，包体积大 |
| `medium` | ~1.5GB | ~5GB | ~0.2x 实时 | 很高 | ❌ 太慢太贵 |
| `large-v3` | ~3GB | ~10GB | ~0.1x 实时 | 最高 | ❌ 桌面不可用 |

**推荐 `base`** — 体积和准确率的最佳平衡。如果中文用户反馈识别差，可考虑 `small`。

### CUDA 回退

Hermes 源码处理了 CUDA 库缺失时的静默回退（`transcription_tools.py` 第 349-373 行）：
```python
# 自动回退逻辑，waifu 用 CPU int8 不需要
WhisperModel(model_name, device="auto", compute_type="auto")
# → CUDA 失败时自动 fallback 到 CPU int8
```
waifu 直接固定 `cpu` + `int8`，省掉这个逻辑。

### 音频格式

Hermes 录音器直接录 16kHz WAV（不需要转码）。waifu 前端录的是 WebM，所以需要一步 ffmpeg 转码：
```
ffmpeg -y -i input.webm -ar 16000 -ac 1 -sample_fmt s16 output.wav
```
**这条命令只有 STT 需要**，TTS 不需要。ffmpeg 已经在 `lib.rs` 里用来做口型能量分析了，所以已经有依赖。

## TTS 反馈保护

> 连续录音模式下 TTS 播放会被麦克风录到，导致 AI 跟自己对话的无限循环。

waifu 用 Push-to-talk（按住才录），所以不存在这个问题。用户 TTS 说话时手不会按着 🎤 按钮。
如果以后想做"免提"持续监听，再参考 Hermes 的 `_tts_playing` Event 保护机制。
