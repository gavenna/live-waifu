# 对话全流程 · 关键日志打印

> 最后更新: 2026-06-30

从用户输入到 AI 回复完成，一条对话经历的所有阶段。每个阶段对应的日志行，方便排查问题。

---

## 完整流程（按时间顺序）

```
用户说话
  │
  ▼
[1] chat-send          ── 前端收到输入
  │
  ├─[2] memory_recall  ── 上下文召回（有结果时才打印）
  │
  ▼
[3] quick_chat_stream   ── Rust 收到请求
  │
  ▼
[4] build_system_prompt ── 开始组装 prompt
[4a]  soul loaded       ── SOUL 字符数
[4b]  USER.md injected  ── 用户画像字节数
[4c]  USER.md is EMPTY  ── 无画像时
[5] system prompt built ── 最终 prompt 字符数
  │
  ▼
[6] chat_stream POST    ── API 请求（含 model、turns、msg_len）
  │
  ▼
[7] response 200        ── API 响应状态 + 首包延迟
  │
  ▼
[8] first chunk         ── 第一个 token 到达（TTFB）
  │
  ▼
[9] chat_stream DONE    ── 流结束（chunks 数、总耗时）
  │
  ▼
[10] emotion detected   ── 前端解析情绪标签
  │
  ▼
[11] TTS invoke done    ── TTS 合成完成（仅当有 TTS 时）
  │
  ▼
[12] response done      ── 前端完整响应
  │
  ├─[13] Memory extracted   ── 事实提取（有记忆基础时才触发）
  │
  └─[14] chat-response emitted ── 结果发送到 ChatWindow
```

## 每条日志详解

### [1] chat-send — 用户消息接收
```
[FRONTEND] [LOG] [App]  chat-send: "用户输入前60字..." mode=fast
```
**位置**：`src/App.tsx` MainWindow `handleChatSend`
**含义**：用户发送了消息，mode 为 fast/relay
**排查**：如果这条没有 → 输入没到达 MainWindow

### [2] memory_recall — 上下文召回
```
[FRONTEND] [LOG] [App] memory_recall: N facts for query: 查询前40字
```
**位置**：`src/App.tsx` MainWindow `handleChatSend`（chat-send 之后、stream 之前）
**含义**：从 facts.json 关键词匹配到 N 条相关记忆
**排查**：
  - 没有这条 → facts.json 为空或 recall 失败（静默回退）
  - N=0 → 无匹配事实

### [3] quick_chat_stream — Rust 端接收
```
[quick_chat_stream] ENTER: url=... model=deepseek-v4-flash key_len=35 user_md_len=0 hist_turns=2 has_tools=true forced_tool=false
```
**位置**：`src-tauri/src/lib.rs` `quick_chat_stream` 命令
**含义**：Rust 收到前端请求，准备调用 LLM
**排查**：`hist_turns`=历史轮次，`has_tools`=是否启用工具调用

### [4] build_system_prompt — 组装 prompt
```
[build_system_prompt] ENTER
[build_system_prompt] soul loaded: 440 chars
[LLM] USER.md injected: 1208 bytes, preview: ...
或
[LLM] USER.md is EMPTY — portrait not generated or file missing
```
**位置**：`src-tauri/src/llm_client.rs` `build_system_prompt()`
**含义**：开始组装 system prompt，记录 SOUL 和 USER 状态

### [5] system prompt built — 最终 prompt 大小
```
[chat_stream] system prompt built: 1157 chars
```
**位置**：`src-tauri/src/llm_client.rs` `chat_stream()`
**含义**：system prompt 最终长度（截断至 10000 chars）
**排查**：很大（>8000）→ 可能有冗余注入；很小（<500）→ SOUL 没加载

### [6] chat_stream POST — API 请求
```
[chat_stream] POST https://api.deepseek.com/v1/chat/completions model=deepseek-v4-flash turns=1 est_tokens≈0K msg_len=2479 has_tools=true
```
**位置**：`src-tauri/src/llm_client.rs` `chat_stream()`
**含义**：
  - `turns` = 历史轮次对（user+assistant）
  - `est_tokens` = 估算 token 数（chars/2）
  - `msg_len` = 当前用户消息长度
  - `has_tools` = 是否启用工具

### [7] response 200 — API 首包延迟
```
[chat_stream] response 200 OK in 303.7831ms
```
**位置**：`src-tauri/src/llm_client.rs` `chat_stream()`
**含义**：API 返回 200，延迟为 HTTP round-trip

### [8] first chunk — TTFB
```
[chat_stream] first chunk in 1.2066958s
```
**位置**：`src-tauri/src/llm_client.rs` `chat_stream()`
**含义**：第一个 token 到达时间（TTFB = Time To First Byte）
**排查**：>3s → 模型响应慢；>10s → 可能超时

### [9] chat_stream DONE — 流完成
```
[chat_stream] DONE: 40 chunks, has_tool_calls=false in 1.9578701s
```
**位置**：`src-tauri/src/llm_client.rs` `chat_stream()`
**含义**：
  - `chunks` = 收到多少个文本增量和 tool_call delta
  - `has_tool_calls` = 模型是否请求了工具调用
  - `in Xs` = 从 POST 到 [DONE] 的总时间

### [10] emotion detected — 情绪识别
```
[FRONTEND] [LOG] [App]  emotion detected: surprised
```
**位置**：`src/hooks/useAgentLoop.ts` `onEmotion` 回调
**含义**：前端从首个 token 的 `[surprised]` 标签解析出情绪

### [11] TTS invoke done — 语音合成
```
[FRONTEND] [LOG] [startup] TTS invoke done 1432 ms, len: 15744
```
**位置**：Rust `edge_tts` 命令 / 前端 TTS 回调
**含义**：TTS 合成完成，`len`=base64 MP3 长度

### [12] response done — 完整响应
```
[FRONTEND] [LOG] [App]  response done: 59 chars, emotion=surprised
```
**位置**：`src/App.tsx` MainWindow `handleChatSend`（stream 完成后）
**含义**：前端完整响应文本长度 + 最终情绪

### [13] Memory extracted — 事实提取
```
[Memory] extracted N facts
```
**位置**：`src-tauri/src/lib.rs` `memory_extract` 命令
**含义**：后台从本轮对话提取了 N 条新事实
**排查**：
  - 没有这条 → `has_knowledge_base` 为 false（USER.md 为空且 facts 为空），冷读保护触发
  - N=0 → 对话没有值得提取的事实

### [14] chat-response emitted — ChatWindow 接收
```
[FRONTEND] emit chat-response: text=..., role=assistant
```
**位置**：`src/App.tsx` MainWindow `handleChatSend`（最后）
**含义**：MainWindow 将 AI 回复发给 ChatWindow

## 启动流程日志

| 顺序 | 日志 | 含义 |
|:--:|------|------|
| 1 | `auto distill...` | 开始蒸馏对话记忆 |
| 2 | `distill done: N thoughts` | 蒸馏完成，N 条念头 |
| 3 | `[Memory] configured OK` | 记忆系统 Python 管线就绪 |
| 4 | `[STT] using small model` | STT 加载 small 模型 |
| 5 | `[STT] daemon ready` | STT 常驻进程就绪 |
| 6 | `[TTS] daemon ready` | TTS 常驻进程就绪 |

## 排查速查表

| 症状 | 看这条日志 |
|------|-----------|
| 回复太长/太慢 | system prompt built chars, chat_stream DONE time |
| 角色不了解我 | USER.md injected / USER.md is EMPTY |
| 角色编造记忆 | memory_recall N（如果 N=0 还编造 → 记忆边界没生效） |
| 不增长记忆 | Memory extracted（冷读保护可能拦截了提取） |
| 回复很蠢 | system prompt built chars（太大=噪音多，太小=缺上下文） |
| TTS 不说话 | TTS invoke done（没有=合成失败） |
| API 慢 | first chunk（首包延迟），chat_stream DONE（总延迟） |
| 搜索关不掉 | chat-send 前无 auto-search 日志 |
