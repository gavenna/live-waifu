## 1. 系统是怎么工作的

```
用户赞助 (爱发电)  →  你生成激活码  →  用户输入激活码  →  绑定设备  →  使用
                     ↑                                      ↓
                  gen-key.ts                           waifu-auth
                                                    (Vercel + Neon)
```

三个核心概念：

| 概念 | 是什么 | 存在哪 |
|------|--------|--------|
| **激活码** | 一次性凭证，用户用它激活软件 | `reg_keys` 表 |
| **Tier** | 用户等级 (trial/pro/dev)，决定设备数和功能 | `users` 表 |
| **Token** | JWT，激活成功后签发，控制登录态 | 用户本地 `license.dat` |

一个激活码 = 一个用户账号 = 一次激活机会。用过就作废。

### 系统架构

```
用户 App (Tauri) → Vercel API (https://waifu-agent.vercel.app/api)
                         ↓
                    Neon (Serverless PostgreSQL)

支付: 爱发电 → 赞助 → 发激活码
```

**当前生产域名**: `https://waifu-agent.vercel.app`
- API 端点: `https://waifu-agent.vercel.app/api/*`
- 管理后台: `https://waifu-agent.vercel.app/admin`（浏览器直接打开）

**你只需要操作两个地方**：
- [管理后台](https://waifu-agent.vercel.app/admin) — 浏览器打开，登录 admin / admin123，查用户、解绑设备、看统计
- [Neon](https://console.neon.tech) — 管理数据库、跑 SQL、复制连接串

### 登录凭据速查

| 服务 | 地址 | 账号 | 备注 |
|------|------|------|------|
| 管理后台 | `waifu-agent.vercel.app/admin` | `admin` / `admin123` | 首次部署后务必改密码 |
| Neon | `console.neon.tech` | 你的邮箱 | 数据库管理 |
| Vercel | `vercel.com` | GitHub 登录 | 看部署日志、改环境变量 |

## 2. 日常操作：收到赞助 → 发激活码

### 你收到的是这样的

爱发电 App/网页通知你："XXX 赞助了你的 Pro 用户档位 ¥19.9/月"

### 你要做的事（10 秒搞定）

1. 打开管理后台：`https://waifu-agent.vercel.app/admin`
2. 在「生成激活码」区域：
   - 选等级（Pro 对应 ¥19.9）
   - 点生成
3. 点「一键复制」或单个复制
4. 在爱发电私信发给用户：

```
感谢赞助！你的激活码：WA-PRO-A3B9-C7D2

使用方法：打开 waifu-agent → 输入激活码 → 点激活。

有效期 30 天，到期续费后发新码。换电脑请私信我处理。
```

### CLI 备用方式（不用开浏览器 / 批量脚本）

```bash
cd waifu-agent/waifu-auth
npx tsx gen-key.ts --tier trial   # 尝鲜 ¥9.9  — 1 设备
npx tsx gen-key.ts --tier pro     # Pro   ¥19.9 — 1 设备
npx tsx gen-key.ts --tier dev     # 开发者 ¥49.9 — 1 设备
npx tsx gen-key.ts --tier pro --count 5 --expires-days 90
```

## 3. 用户问题处理

### 场景 A：用户换了新电脑

```bash
# Step 1: 管理员登录
TOKEN=$(curl -s -X POST https://waifu-agent.vercel.app/api/admin-login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"你的密码"}' \
  | python -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])")

# Step 2: 查用户列表，找到对应 user_id
curl -s "https://waifu-agent.vercel.app/api/admin-users?limit=50" \
  -H "Authorization: Bearer $TOKEN"

# Step 3: 解绑旧设备
curl -s -X POST "https://waifu-agent.vercel.app/api/admin-users/<用户ID>/unbind-all" \
  -H "Authorization: Bearer $TOKEN"

# Step 4: 发新激活码
npx tsx gen-key.ts --tier pro
```

### 场景 B：用户续期

**方式一（推荐）**：直接延长 tier，不需新激活码。Neon → SQL Editor：
```sql
UPDATE users SET device_limit = 1 WHERE id = <用户ID>;
```

用户什么都不用做，下次启动自动续期。

**方式二**：生成新激活码发给用户，用户重新激活一次。

### 场景 C：激活码泄漏

```bash
# 解绑所有设备 → 生成新码
curl -s -X POST "https://waifu-agent.vercel.app/api/admin-users/<用户ID>/unbind-all" \
  -H "Authorization: Bearer $TOKEN"
npx tsx gen-key.ts --tier pro
```

提醒用户不要转发激活码。

### 场景 D：封禁用户

```bash
# 封禁（所有 token 立即失效）
curl -s -X POST "https://waifu-agent.vercel.app/api/admin-users/<用户ID>/ban" \
  -H "Authorization: Bearer $TOKEN"

# 解封（同一个命令再发一次）
```

## 4. 管理后台操作

### 方式一：浏览器管理后台（推荐）

直接打开 `https://waifu-agent.vercel.app/admin`，登录后可以：
- 查看用户列表、设备绑定、激活码状态
- 封禁/解封用户
- 修改用户等级和设备上限
- 解绑设备

### 方式二：API 命令行

```bash
BASE="https://waifu-agent.vercel.app/api"

# 管理员登录
TOKEN=$(curl -s -X POST $BASE/admin-login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' \
  | python -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])")

# 用户列表
curl -s "$BASE/admin-users" -H "Authorization: Bearer $TOKEN"
```

### 方式三：数据库直查（Neon → SQL Editor）

### 查看某用户详情

```bash
curl -s "https://waifu-agent.vercel.app/api/admin-users/3" \
  -H "Authorization: Bearer $TOKEN"
```

返回 tier、设备列表、使用的激活码。

### 修改用户等级

```bash
curl -s -X PUT "https://waifu-agent.vercel.app/api/admin-users/3" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"tier":"pro","device_limit":1}'
```

### 查看统计

```bash
curl -s "https://waifu-agent.vercel.app/api/admin-stats" \
  -H "Authorization: Bearer $TOKEN"
```

### 数据库直查（Neon → SQL Editor）

```sql
-- 所有 Pro 用户
SELECT id, tier, status, created_at FROM users WHERE tier = 'pro';

-- 某用户绑了哪些设备
SELECT * FROM devices WHERE user_id = 3;

-- 最近生成的激活码
SELECT key, tier, status, used_by, created_at FROM reg_keys ORDER BY created_at DESC LIMIT 20;

-- 还剩多少未用的激活码
SELECT tier, COUNT(*) FROM reg_keys WHERE status = 1 AND expires_at > NOW() GROUP BY tier;
```

## 5. 部署与维护

### 当前部署配置

| 设置 | 值 |
|------|-----|
| Vercel 站点 | `waifu-agent.vercel.app` |
| Base directory | `waifu-auth` |
| Framework Preset | Other |
| Build command | `echo 'Skipping build'` (vercel.json 覆盖) |
| Functions directory | `api/` (预编译 .js) |
| 配置文件 | `waifu-auth/vercel.json` |

### 系统依赖

| 组件 | 产品 | 费用 |
|------|------|------|
| 代码托管 | GitHub | $0 |
| API 服务 | Vercel Functions | $0 (125k 次/月) |
| 数据库 | Neon | $0 (0.5GB) |
| 支付 | 爱发电 | ~6% 手续费 |

### 更新后端代码

```bash
git add -A
git commit -m "改了什么"
git push origin main
```

Vercel 自动部署，约 1 分钟后生效。去 Vercel → Deploys 确认。

### 本地测试

```bash
# 终端 1: 启动本地 auth 服务器
cd waifu-auth && npx tsx server.ts    # → localhost:3456

# 终端 2: 启动 Tauri（连本地 auth）
AUTH_API_URL=http://localhost:3456/api ./node_modules/.bin/tauri dev
```

### 环境变量（Vercel Dashboard → Settings → Environment Variables）

| 变量 | 用途 | 状态 |
|------|------|:--:|
| `DATABASE_URL` | Neon 数据库连接字符串（所有 context） | ✅ 已设 |
| `JWT_SECRET` | Access Token / Refresh Token 签名密钥（所有 context） | ✅ 已设 |

本地开发需在 `waifu-auth/.env` 中设 `DATABASE_URL`，`JWT_SECRET` 用默认值即可。

### 管理员密码

默认 `admin / admin123`。**首次部署务必修改**：

1. https://bcrypt-generator.com/ 生成 bcrypt hash
2. Neon → SQL Editor：
```sql
UPDATE admins SET password = '<生成的 hash>' WHERE username = 'admin';
```

### 清空测试数据

```sql
DELETE FROM refresh_tokens;
DELETE FROM devices;
DELETE FROM reg_keys;
DELETE FROM users;
```

## 6. 故障排查速查表

| 现象 | 先查这个 | 怎么修 |
|------|---------|--------|
| 用户激活失败 | 激活码是否被用过？<br>`reg_keys` 表查 `status` | 已用 → 发新码<br>过期 → 发新码 |
| "设备数已满" | 该用户绑了多少设备？<br>`SELECT * FROM devices WHERE user_id = X` | 解绑旧设备或升级 tier |
| 用户打不开 App | token 全过期（30天没开） | 发新激活码 |
| 所有 API 挂了 | Vercel 部署状态？ | Vercel → Deploys |
| 数据库连不上 | Neon 是否休眠？ | Neon Console → Resume |
| 本地 API 404 | 服务器没启动？ | `cd waifu-auth && npx tsx server.ts` |
| gen-key 报错 | DATABASE_URL 没设？ | 检查 `.env` 文件 |
| admin token 过期 | JWT 2h 有效期 | 重新登录 |

### 快速诊断

```bash
# API 活着吗？
curl -s https://waifu-agent.vercel.app/api/admin-login

# 还剩多少激活码？
# Neon → SQL Editor:
# SELECT COUNT(*) FROM reg_keys WHERE status = 1 AND expires_at > NOW();
```
