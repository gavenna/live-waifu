## 正文

你想象过桌面上有一个**活的**角色吗？

不是静态壁纸，不是只会复读的聊天机器人。她眼睛会眨、嘴会跟着说话动、能听出你开心还是难过、会用对应的表情回应你。

**waifu-agent** 就是做这个的。


### 这不是"又一个 AI 聊天软件"

市面上有太多 AI 聊天 App 了，但它们几乎都只有一个聊天框。waifu-agent 不一样：

- ❌ 不是写死的聊天脚本 → 背后接的是 DeepSeek 大模型，每次回复都不一样
- ❌ 不是只有一张图的桌宠 → 表情、口型、动作、贴图全部实时联动
- ❌ 不是只能聊天 → 开发者可以把 waifu-agent 当成自己的 Agent 前端界面

### 那它到底是什么

当 waifu-agent 运行时，你桌面上会出现一个 **600×800 的透明悬浮窗**。角色站在半透明的背景上，会呼吸（胸口起伏），会眨眼，会不经意地做小动作。

你用键盘打字 → LLM 处理 → 角色开口说话（**口型同步**，嘴型真的在匹配发音） → 语音播放。

关键是**情绪系统**。模型会根据对话内容判断情绪，然后角色的表情会变：

- 开心时眉眼弯弯，动作频率加快
- 不好意思时脸红扭头
- 生气时会鼓起嘴 + 动作幅度变大
- 说了什么抽象的 → 弹出一个 chibi 贴图

7 种情绪，每种都会触发面部表情 + 动作 + 贴图三重联动。这不是在聊天框里加 emoji——这是角色真的在"演"。

### 两种使用方式

**模式一：开箱即用**

填个 DeepSeek API key，装好就能聊。什么都不用配。适合大多数人。

**模式二：开发者中继（Relay）**

waifu-agent 通过 WebSocket 暴露一个开放协议。你可以接任何 Agent 系统进来——Hermes、OpenClaw、你自己写的 AI agent。waifu-agent 只做"脸"的部分，Agent 的大脑逻辑你自己控制。

如果你是一个在捣鼓 AI Agent 的开发者——waifu-agent 可以是你 Agent 的**表情和声音前端**。

### 开发者的话

我叫 gaven，一个人在做这个项目。

做 waifu-agent 的初衷其实很简单：现在的 AI 太强了，但全都住在聊天框里。我想让 AI 有一张脸，有表情，有声音——让你感觉桌面上真的多了一个角色。

技术上踩了很多坑。Live2D Cubism 4 在 Pixi.js 上的渲染管线、42 韵母到 5 元音的逐字口型映射、Python 运行时嵌入 MSI 安装包做到零依赖、WebSocket 双向 Relay 协议设计……每一个都花了不少时间。

产品还很不完美——角色只有两个、还没有点击穿透、切换还不够顺滑——但**已经可以用了**。

我希望有人真正把它用起来，告诉我什么做得好、什么该砍掉、你最想要什么功能。
