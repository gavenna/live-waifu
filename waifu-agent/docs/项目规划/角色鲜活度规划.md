## 已完成

### 一、🎭 表情 — 情绪驱动 ✅

LLM 输出 `[happy]` `[sad]` `[angry]` `[surprised]` `[shy]` `[loving]` `[neutral]` 标签 → 前端解析 → 表情/动作联动。

| 文件 | 职责 |
|------|------|
| `SOUL.md` | "你的情绪表达"段落，指导 LLM 输出标签 |
| `src/constants/emotion.ts` | Emotion 类型、EMOTION_EXPRESSION 映射、EMOTION_MOTION_BIAS 偏置、关键词 fallback |
| `src/hooks/useChatStream.ts` | 流式文本中正则匹配标签 → onEmotion()，200 chars 无标签则 fallback |
| `src/App.tsx` | ticker: 表情=EMOTION_EXPRESSION[emotion]，动作=EMOTION_MOTION_BIAS 频率+特效偏置，情绪保持 15s |

映射表：
```
happy→exp_02(微笑) sad→exp_05 angry→exp_08 surprised→exp_04
shy→exp_06 loving→exp_07 neutral→exp_01
```

### 二、🔊 语音 — 流式 TTS ✅

LLM SSE 流式 → 逐句切分 → TTS 生成&播放并行。首句延迟 1-2s。

| 文件 | 职责 |
|------|------|
| `src-tauri/src/llm_client.rs` | `chat_stream()` SSE 流式 HTTP |
| `src-tauri/src/lib.rs` | `quick_chat_stream` command |
| `src/hooks/useChatStream.ts` | 流式管理: 情绪→切句→TTS 队列→播放 |
| `src/hooks/useTts.ts` | `generate()` AudioBuffer + `playBuffer()` 独立 |

### 三、👄 口型 — 5 元音形状 ✅

取代旧的 4 级离散口型 (mouth_lv0~open)。用拼音韵母映射到 Live2D 的 5 个元音参数 (ParamA/I/U/E/O)，每字嘴型不同。写入时机在 Cubism4 `beforeModelUpdate` 事件（step 10），防 motion/表情覆盖。

| 文件 | 职责 |
|------|------|
| `src/utils/vowelShape.ts` | pinyin-pro 逐字拆韵母 → 42 韵母 → {a,i,u,e,o} 5 维权重 |
| `src/hooks/useTts.ts` | `generateEnergy()` 输出 `VowelFrame[]`（每格 100ms） |
| `src/App.tsx` | `beforeModelUpdate` 写 5 元音 + MouthDown（连续值） |
| `src/persona.config.ts` | Mao paramIds: mouthOpen=ParamA, mouthI/U/E/O, mouthUp/Down |

参数保真度：
```
ParamA      ~90%  (LipSync 组保护)
ParamI/U/E/O ~90% (×3 补偿管线衰减)
MouthDown   100%
MouthUp     不写 (range 限制)
```
