# Claude Code 记忆系统

> 给**人**看的参考。AI 每次会话自动加载，你随时可以自己打开编辑。

---

## 它是什么

Claude Code 内置的文件级记忆。每次新会话启动时，自动加载索引，根据对话内容召回相关记忆注入 AI 上下文。

**不是** waifu-agent 的角色记忆（那个在 `%APPDATA%/com.waifu-agent.app/memory/`），**是** Claude Code 对**你这个项目**的持续认知。

## 结构

```
memory/
├── MEMORY.md           ← 索引，每次会话加载这个文件
├── *.md                ← 内容文件，被索引命中后才加载正文
```

| 文件 | 谁看 | 加载时机 |
|------|------|---------|
| `MEMORY.md` | AI（索引） | 每次会话开头必加载 |
| `*.md` | AI + 人 | 索引命中后注入上下文 |

---

## 文件格式

每条记忆一个 `.md` 文件，头部是 YAML：

```yaml
---
name: kebab-case-slug        # 唯一 ID
description: 一句话摘要       # AI 用它判断相关性
metadata:
  type: user | feedback | project | reference
---

正文。

链接其他记忆用 [[other-slug]]。

**Why:** 为什么有这个规则。
**How to apply:** AI 怎么执行。
```

---

## 四种类型

| type | 存什么 |
|------|--------|
| `user` | 你的偏好、风格、角色 |
| `feedback` | 你给 AI 的纠正和指导 |
| `project` | 项目架构、约束、设计决策 |
| `reference` | 外部链接、文档 URL |

## 你可以做什么

| 操作 | 方法 |
|------|------|
| 查看全部 | 打开 `MEMORY.md` |
| 看某条内容 | 点开对应 `.md` 文件 |
| 修改内容 | 直接编辑 `.md` 文件 |
| 删除一条 | 删文件 + 从 `MEMORY.md` 移除对应行 |
| 新增一条 | 新建 `.md` 文件 + 在 `MEMORY.md` 加一行 |
| 告诉 AI 改 | 说"更新 xxx 那条记忆"或"删掉 xxx" |

---

## AI 的写入规则

- 查重：已有同类条目就更新，不新建
- 不存代码能推导的（git log、目录结构、已有注释）
- 不存只在本次对话有意义的东西
- `feedback` 和 `project` 类型正文末尾带 **Why** + **How to apply**
