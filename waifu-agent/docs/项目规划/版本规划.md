# waifu-agent 版本规划

> 最后更新: 2026-07-05

---

## 定位

**给 AI Agent 一张有表情有声音的脸。** 不是会聊天的桌宠。

目标用户：构建 AI Agent 的开发者。商业模式：本体免费 + Relay 开放 + 付费皮肤/高级功能。

## 已知限制

- 模型数量少 (2 个)，需模型导入系统
- 语音输入需打包预下载 faster-whisper base 模型 (~150MB)
- CSP 为空 (Tauri 本地 WebView，风险低)
- API key 明文存储 (`llm_config.json`)
- 部分 Windows DPI 缩放下窗口位置可能偏移
- lib.rs 1748 行 / App.tsx 1570 行，后续可拆分
- 🔴 P0: 记忆系统断链 — ✅ 已修复 (2026-06-29: 新增吸收管线 api.py absorb_unabsorbed_facts + cli.py extract 接线)
- 🟡 用户消息重复写入 — ✅ 已修复 (语音路径 + ChatWindow 打字路径均已验证正常)
