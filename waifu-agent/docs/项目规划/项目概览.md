# waifu-agent 项目概览

> 最后更新: 2026-06-01

---

## 一句话定位

**不是会聊天的桌宠，是给 Agent 一张有表情有声音的脸。**

桌面 Live2D 角色 + AI Agent 前端。Tauri 2 桌面应用，给 Hermes/DeepSeek 一个可视化动漫形象。

- **当前版本**: v0.7.x
- **默认角色**: mao (Live2D model)
- **窗口**: 600×800 透明无框置顶悬浮窗

## 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | Tauri 2 (Rust 后端 + WebView2 前端) |
| 前端 | React 18 + TypeScript 5 + Vite 5 |
| 渲染 | Pixi.js 7 + pixi-live2d-display (Cubism 4) |
| AI 后端 | DeepSeek API (快速) / Hermes Agent CLI (深度) |
| 通信 | WebSocket 9191 端口 (agent 状态) + Tauri events (窗口间) |
| 语音 | Edge TTS (Python edge-tts → Azure Xiaoxiao) + Web Audio 播放 |
| 语音输入 | faster-whisper base 模型 (空格按住说话, ffmpeg 转码) |
| 记忆 | SOUL.md (编译嵌入) + USER.md (用户编辑) + MEMORY.md (AI 按规则写入) |
| 包管理 | npm (Node) + cargo (Rust) + scoop (Windows 系统工具) |

## 三窗口系统

| 窗口 | label | URL | 功能 |
|---|---|---|---|
| MainWindow | `main` | `/` | PIXI 角色 + 按钮 + WS 状态 + LLM 中继 |
| SettingsWindow | `settings` | `?view=settings` | 设置面板 |
| ChatWindow | `chat` | `?view=chat` | 聊天面板 |

窗口间通过 Tauri events 通信。设置面板保存后 `emit("settings-updated")`，主窗口 `listen` 接收。

## 核心数据流 (v0.6.x)

### 完整语音对话管线

```
语音/文字输入
  │  emit("chat-send")
  ▼
Rust 后端 (quick_chat_stream)
  │  SSE 流式 HTTP → emit("chat-chunk") 每个 token
  │  emit("chat-done") 流结束
  ▼
useChatStream hook (前端流式处理)
  ├─ ① 情绪标签解析 [happy]/[sad]/... → onEmotion()
  ├─ ② 标点切句 → ttsQueue 排队
  └─ ③ 逐句 TTS: invoke("edge_tts") → playBuffer() 生成&播放并行
  ▼
PIXI ticker (每帧)
  ├─ 口型: beforeModelUpdate 写 ParamA/I/U/E/O + MouthDown (5 元音连续值)
  ├─ 表情: EMOTION_EXPRESSION[emotion] → exp_02/05/08/... (情绪驱动)
  └─ 动作: EMOTION_MOTION_BIAS[emotion] → TapBody 偏置 (频率+特效)
  ▼
后处理: save_turn / append_memory / historyRef
```

### 口型架构 (v0.6.x 关键改进)

```
generateEnergy(text) → pinyin-pro 韵母映射
  ├─ 逐字拆韵母 → 42 韵母 → 5 元音权重 (a/i/u/e/o)
  └─ 正弦波调幅 + 噪声 → VowelFrame[] (100ms/格)

beforeModelUpdate 事件 (Cubism4 step 10, 防 motion 覆盖)
  ├─ ParamA = frame.a * amplitude (LipSync 组保护)
  ├─ ParamI/U/E/O = frame.i/u/e/o * amplitude * 3 (补偿衰减)
  ├─ MouthDown = smooth.mouth (连续，替代 4 级离散)
  └─ 读回验证: ParamI/U/E/O ~90% 保真, MouthDown 100%
```

### 深度模式 (Hermes，基本不可用)

```
用户输入 → Hermes CLI 子进程 → 工具调用/多步推理
                                ↓
                    WebSocket 9191 → agent:start/step/end
```
