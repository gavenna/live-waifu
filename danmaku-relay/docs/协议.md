# 弹幕中继协议

## 拓扑

```
douyinLive.exe (:1088)     B站 WS (wss://)
        ↓                        ↓
   douyin.js               bilibili.js
        ↓                        ↓
        └──────── Relay :8766 ────┘
                      ↓
              订阅方 (游戏、监控、录播...)
```

## 消息类型

### `danmaku` — 弹幕/社交事件

```json
{
  "type": "danmaku",
  "text": "杀",
  "playerId": "douyin_123456",
  "playerName": "观众名",
  "displayText": "感谢 观众名 的 100 连赞！⚔ 民兵前来助阵"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | 固定 `"danmaku"` |
| `text` | string | ✅ | 弹幕内容，≤50字符，由游戏侧查指令表（`1`/`红`=入红方，`杀`=出兵等） |
| `playerId` | string | ✅ | 平台前缀 + uid：`bili_<uid>` / `douyin_<uid>` |
| `playerName` | string | 可选 | 缺省回退为 playerId |
| `displayText` | string | 可选 | 抖音点赞/关注/分享时附带的悬浮文案 |

### `gift` — 礼物（按价值加余额 / 专属召唤）

```json
{
  "type": "gift",
  "troopKey": "dragonKnight",
  "giftId": "1234",
  "giftName": "龙骑士",
  "playerId": "bili_456",
  "playerName": "老板",
  "coinValue": 100,
  "coinUnit": "gold",
  "count": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | 固定 `"gift"` |
| `troopKey` | string | 可选 | **遗留字段**：适配器仍填，中继已不消费（B站适配器拿它当"认不认这个礼物"的放行门禁） |
| `giftId` | string | 可选 | 平台原始礼物 ID |
| `giftName` | string | 可选 | 平台礼物名（按名匹配专属召唤；也用于感谢语） |
| `coinValue` | number | 可选 | 礼物价值原值（抖音=抖币；B站=金瓜子） |
| `coinUnit` | string | 可选 | `"diamond"`（抖音抖币）/ `"gold"`（B站金瓜子，÷100 折算成抖币当量） |
| `count` | number | 可选 | 礼物个数（连刷数），缺省按 1 |
| `playerId` | string | ✅ | 同上格式 |
| `playerName` | string | 可选 | 昵称 |

> **中继消费规则**（2026-10）：`giftName` 含「闪耀星辰」→ 直接召唤 1 个执行者；否则按 `coinValue` 折算抖币当量（**1 抖币 = 50W**）给该观众归属阵营的**观众钱包**加余额。

### `join` — 进房自动加入阵营

```json
{
  "type": "join",
  "team": "red",
  "playerId": "douyin_789",
  "playerName": "观众"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | 固定 `"join"` |
| `team` | string | ✅ | `"red"` 或 `"blue"` |
| `playerId` | string | ✅ | 同上格式 |
| `playerName` | string | 可选 | 昵称 |

## 兵种 key 词表

`militia` `spearman` `bowman` `raider` `swordsman` `knight` `archer` `catapult` `royalGuard` `fireArrow` `batteringRam` `giant` `dragonKnight` `wrathOfGod` `warChest`

## 连接规范

- **传输**: WebSocket, 文本帧 (JSON)
- **校验**: 每条消息必须有 `type` 字段，无 type 的消息被丢弃
- **玩家 ID**: `bili_<uid>` 或 `douyin_<uid>`，不可为空
- **team**: 只能是 `"red"` / `"blue"`
- **重连**: 订阅方断线后 exponential backoff (1s→2s→4s…→上限30s)
