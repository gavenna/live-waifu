# danmaku-relay 测试指南

## 一键自动测试 (推荐)

```bash
node test.js    # 或双击 test.bat
```

脚本自动完成 7 步,全程无需人工干预:

| 步骤 | 动作 | 断言 |
|------|------|------|
| [1] 服务检查 | 探测 :8767;未运行则自动拉起 `node index.js` | 10s 内就绪 |
| [2] 控制面板 | GET `/`、`/style.css`、`/api/logs`、`/api/config` | 静态页 200 / 日志环形缓冲有数据 / 配置字段齐全 |
| [3] 配置写入 | POST `/api/config/save` 写入测试配置(proxyUrl → 模拟器 :12011) | 保存成功 + 读回一致 |
| [4] 模拟器 | 拉起 `danmaku/douyin-test.js`(:12011,模拟 douyinLive) | 进程存活 |
| [5] 适配器 | 调 `/api/start-douyin` | `adapter:true` + 模拟器确认收到连接 |
| [6] 事件链路 | WS 订阅 :8766,向模拟器发送 dm/gift/like/enter/follow | — |
| [7] 链路断言 | 校验收到的消息 | 6 项(见下) |

**链路断言项**:

- `dm 杀` → danmaku 消息,text=`杀`
- `gift 城堡 520` → gift,`troopKey=giant`
- `like 100` → danmaku 百赞连击,`displayText` 含 `100 连赞`
- `enter` → join,`team=red|blue`
- `follow` → danmaku 关注文案 + gift `militia`(关注奖励)

**判定**: 输出 `13/13 PASS ✓ 链路全部通畅` 即通过。
**收尾**: 自动恢复 secrets.json、停适配器、关服务(零残留),结束时打印"服务已关闭"。

## 复用已有服务时的行为

若 :8767 已在运行(比如你开着 start-all.bat),测试脚本**复用**它:
- 不杀你的进程,结束时归还原适配器状态(测试前在跑的会自动重启)
- 中途会短暂把抖音适配器切到模拟器,测试完还原

## 手动冒烟步骤 (不开直播快速验)

1. 双击 `start-all.bat` → 自动开服务 + 适配器 + 浏览器控制面板
2. 浏览器 `http://localhost:8767` → 点「📡 启动抖音」「📺 启动B站」「■ 全部停止」,看状态卡与事件日志联动
3. `node danmaku/douyin-test.js` 手动连模拟器,输入 `dm 杀` / `gift 城堡 520` / `like 100`,订阅方应收到对应消息
4. 订阅验证:
   ```js
   const WebSocket = require('ws');
   const ws = new WebSocket('ws://localhost:8766');
   ws.on('message', d => console.log(JSON.parse(d.toString())));
   ```

## 注意

- 测试期间 `server/secrets.json` 会被临时改写(抖音 proxyUrl → :12011),自动备份恢复,无需手动处理
- 测试不依赖 `tools/douyinLive.exe`(用模拟器替代),不影响真实抖音直播
- B站适配器不在此测试范围(需真实 cookie + 直播间),由 `npm run check` 保证语法
