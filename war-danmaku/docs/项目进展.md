## 关键决策记录

| 日期 | 决策 | 原因 |
|------|------|------|
| 2026-07 | Node.js 而非 Python | 前后端同语言，WS 生态成熟 |
| 2026-07 | 纯 Canvas 而非 Cocos/Unity | 学习成本低，OBS 兼容好 |
| 2026-07 | 自建 logger 不引入第三方 | 项目只有 ws 一个依赖 |
| 2026-07 | B站协议开发调试，抖音上线 | B站弹幕协议开放，无需审核 |
| 2026-07-13 | 放弃 Rusted Warfare mod 路线 | RW 无外部输入 API，纯 INI 封闭系统 |
| 2026-07-13 | 放弃 open-block-war fork | 格点占点模型太简单 |
| 2026-07-13 | 保留 war-danmaku 后端，前端 Canvas | 后端 RTS 逻辑已完整，换渲染层即可 |
| 2026-07-13 | B站弹幕中继用 Python blivedm | Node.js 生态无同等质量 B站协议库 |
| 2026-07-13 | blivedm 必须用 GitHub 版非 PyPI | PyPI 0.1.1 不支持 Wbi 签名（-352 错误） |
| 2026-07-13 | 精灵图用 `/artist` skill 管理 | Art Bible 统一标准 > 随手生成 |
