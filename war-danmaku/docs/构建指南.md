# 构建指南

> `node build.js` 一键构建单 exe 分发包。Node.js SEA (Single Executable Application) 方案。

## 前置条件

- Node.js v18+（构建用，用户端不需要）
- Inno Setup 6+（可选，仅生成安装包时需要）

## 构建步骤

```bash
node build.js
```

全程自动，分 5 步：

| 步骤 | 做什么 | 产物 |
|------|--------|------|
| 1. WASM 编码 | `node_modules/sql.js/dist/sql-wasm.wasm` → base64 → `server/sql-wasm-data.js` | 临时文件（构建完删） |
| 2. esbuild bundle | `server/index.js` + 所有依赖 → 单文件 bundle | `dist/bundle.js`（中间产物） |
| 3. SEA 注入 | bundle → blob → 注入 Node.js 二进制 | `dist/war-danmaku.exe`（~89 MB） |
| 4. 组装分发目录 | exe + 静态文件 + 配置模板 → 完整目录 | `dist/war-danmaku/` |
| 5. 安装包 | Inno Setup 打包（无 iscc 则跳过） | `dist/war-danmaku-setup-v1.0.exe`（~95 MB） |

## 产物结构

```
dist/war-danmaku/
├── war-danmaku.exe          ← 主程序，双击运行
├── frontend/                ← 游戏画面（OBS 浏览器源）
├── assets/                  ← 精灵图等美术资源
├── toolbox/                 ← 控制面板前端
│   ├── index.html
│   ├── style.css
│   └── app.js
├── tools/
│   └── douyinLive.exe       ← 抖音弹幕代理
└── server/
    ├── secrets.json          ← 用户配置（首次自动生成模板）
    └── secrets.json.example  ← 配置模板
```

## 运行

```bash
# 开发时直接用 Node.js
node server/index.js

# 分发后双击 exe 或命令行
.\dist\war-danmaku\war-danmaku.exe
```

启动后四个端口：
- `:3000` — OBS 游戏画面
- `:8760` — 控制面板
- `:8765` — 游戏 WebSocket
- `:8766` — 弹幕中继 WebSocket

## 用户配置

首次运行后编辑 `server/secrets.json`：

```json
{
  "douyin": {
    "enabled": true,
    "roomId": "直播间房间号",
    "cookie": "从浏览器 F12 → Network 复制的完整 Cookie 头"
  },
  "bilibili": {
    "roomId": 0,
    "cookie": ""
  }
}
```

配置完重启 exe，在控制面板 (`:8760`) 点击对应按钮启动。
