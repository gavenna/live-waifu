## 错误复盘

1. **先改代码后验证上游** — douyin.js 改完了才发现 douyinLive 连不上直播间。原因：房间号需要 cookie 鉴权，先验证能通再改适配器才对。流程问题，已有 Memory `diagnose-data-flow-first` 覆盖。

2. **document.cookie 遗漏 HttpOnly** — 让用户跑了两次才拿到正确的 Cookie。原因：sessionid 是 HttpOnly 的，Console 里拿不到。知识问题，已写入 pitfalls G12。

3. **Playwright 过度设计** — 上了一套扫码自动登录方案，被否决。原因：没先评估"一辈子只做一次"的操作不该自动化。用户偏好，已写入 Memory `prefer-simple-over-automation`。
