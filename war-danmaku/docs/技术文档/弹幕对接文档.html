可遇AI弹幕工具 - API对接文档

📖 概述

可遇AI弹幕工具是一个基于Electron开发的跨平台直播弹幕抓取工具，通过WebSocket技术提供实时弹幕数据接口。本文档详细介绍如何连接WebSocket服务、数据传输格式以及各平台数据结构。

🔌 WebSocket连接

连接信息

  • 服务地址: ws://localhost:12011 或 ws://127.0.0.1:12011
  • 协议: WebSocket
  • 端口: 12011（固定端口）
  • 连接方式: 标准WebSocket连接，无需认证

连接示例

JavaScript连接示例

// 创建WebSocket连接
const ws = new WebSocket('ws://localhost:12011');

// 连接成功
ws.onopen = function(event) {
    console.log('WebSocket连接已建立');
};

// 接收消息
ws.onmessage = function(event) {
    try {
        const data = JSON.parse(event.data);
        console.log('收到弹幕数据:', data);
        // 处理弹幕数据
        handleBarrageData(data);
    } catch (error) {
        console.error('数据解析失败:', error);
    }
};

// 连接关闭
ws.onclose = function(event) {
    console.log('WebSocket连接已关闭');
};

// 连接错误
ws.onerror = function(error) {
    console.error('WebSocket错误:', error);
};

Python连接示例

import websocket
import json

def on_message(ws, message):
    try:
        data = json.loads(message)
        print(f"收到弹幕数据: {data}")
        # 处理弹幕数据
        handle_barrage_data(data)
    except json.JSONDecodeError as e:
        print(f"数据解析失败: {e}")

def on_error(ws, error):
    print(f"WebSocket错误: {error}")

def on_close(ws, close_status_code, close_msg):
    print("WebSocket连接已关闭")

def on_open(ws):
    print("WebSocket连接已建立")

# 创建WebSocket连接
ws = websocket.WebSocketApp("ws://localhost:12011",
                          on_open=on_open,
                          on_message=on_message,
                          on_error=on_error,
                          on_close=on_close)

# 开始连接
ws.run_forever()

Node.js连接示例

const WebSocket = require('ws');

// 创建WebSocket连接
const ws = new WebSocket('ws://localhost:12011');

// 连接成功
ws.on('open', function open() {
    console.log('WebSocket连接已建立');
});

// 接收消息
ws.on('message', function message(data) {
    try {
        const jsonData = JSON.parse(data.toString());
        console.log('收到弹幕数据:', jsonData);
        // 处理弹幕数据
        handleBarrageData(jsonData);
    } catch (error) {
        console.error('数据解析失败:', error);
    }
});

// 连接关闭
ws.on('close', function close() {
    console.log('WebSocket连接已关闭');
});

// 连接错误
ws.on('error', function error(err) {
    console.error('WebSocket错误:', err);
});

📊 JSON数据传输格式

数据传输协议

  • 数据格式: JSON字符串
  • 编码: UTF-8
  • 传输方向: 单向（服务器 → 客户端）
  • 数据类型: 实时弹幕、礼物、点赞、关注等互动数据

通用数据结构

所有平台的数据都遵循以下基本结构：

{
    "uid": "用户唯一标识",
    "name": "用户昵称",
    "msgType": "消息类型",
    "msgId": "消息ID",
    "timestamp": "时间戳",
    "platform": "平台标识"
}

🚀 快速开始

1. 启动弹幕工具

  1. 运行可遇AI弹幕工具应用
  2. 应用会自动启动WebSocket服务器（端口12011）
  3. 在应用中输入直播间链接并进入直播间

2. 连接WebSocket

// 简单的连接示例
const ws = new WebSocket('ws://localhost:12011');

ws.onmessage = function(event) {
    const data = JSON.parse(event.data);
    console.log('收到数据:', data);
    
    // 根据消息类型处理数据
    switch(data.msgType) {
        case '弹幕':
            console.log(`${data.name}: ${data.content}`);
            break;
        case '礼物':
            console.log(`${data.name} 送了 ${data.giftCount} 个 ${data.giftName}`);
            break;
        case '点赞':
            console.log(`${data.name} 点了 ${data.count} 个赞`);
            break;
        case '关注':
            console.log(`${data.name} 关注了主播`);
            break;
        case '进房':
            console.log(`${data.name} 进入了直播间`);
            break;
    }
};

3. 处理数据

function handleBarrageData(data) {
    // 数据验证
    if (!data.msgType || !data.name) {
        console.warn('无效数据:', data);
        return;
    }
    
    // 根据平台和消息类型处理数据
    const platform = detectPlatform(data);
    
    switch(data.msgType) {
        case '弹幕':
            displayBarrage(data);
            break;
        case '礼物':
            displayGift(data);
            break;
        case '点赞':
            displayLike(data);
            break;
        // ... 其他消息类型
    }
}

function detectPlatform(data) {
    if (data.uid && data.uid.startsWith('MS4wLjABAAAA')) {
        return data.secUid ? 'tiktok' : 'douyin';
    } else if (data.uid && data.uid.startsWith('wxid_')) {
        return 'weixin';
    }
    return 'unknown';
}

⚠️ 注意事项

连接注意事项

  1. 端口占用: 确保12011端口未被其他程序占用
  2. 防火墙: 检查防火墙设置，允许12011端口通信
  3. 本地连接: 服务仅监听本地地址，外部无法直接访问
  4. 自动重连: 建议实现自动重连机制，处理网络异常

数据处理注意事项

  1. 数据验证: 始终验证接收到的JSON数据格式
  2. 异常处理: 妥善处理数据解析异常和网络异常
  3. 内存管理: 长时间运行时注意内存使用情况
  4. 平台差异: 不同平台的数据字段可能有差异，需要兼容处理

性能优化建议

  1. 批量处理: 对于高频数据，考虑批量处理以提高性能
  2. 数据过滤: 根据需求过滤不必要的数据类型
  3. 缓存机制: 对于用户信息等相对稳定的数据，可以实现缓存
  4. 异步处理: 使用异步方式处理数据，避免阻塞主线程

🔍 故障排除

常见问题

  1. 无法连接WebSocket

    • 检查弹幕工具是否正常运行
    • 确认端口12011未被占用
    • 检查防火墙设置

  2. 收不到数据

    • 确认已在弹幕工具中进入直播间
    • 检查直播间是否有实际的弹幕互动
    • 验证WebSocket连接状态

  3. 数据格式异常

    • 检查JSON解析代码
    • 验证数据字段是否存在
    • 查看控制台错误信息

  4. 连接频繁断开

    • 实现心跳检测机制
    • 添加自动重连逻辑
    • 检查网络稳定性

调试建议

  1. 启用日志: 在代码中添加详细的日志输出
  2. 使用测试页面: 利用提供的websocket-test.html进行测试
  3. 监控连接状态: 实时监控WebSocket连接状态
  4. 数据验证: 对接收到的每条数据进行格式验证
