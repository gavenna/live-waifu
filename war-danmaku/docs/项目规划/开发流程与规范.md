## 代码规范

### 语言与风格

- 中文回复、中文注释
- 不写冗长注释，不写 JSDoc，代码自解释
- UI：全 inline styles，无 CSS 框架，暗色半透明风
- 改动原则：一次修一类问题，不蔓延；发现模式后再统一重构

### Git

- 不主动 commit，等用户指示
- 测试：用户手动肉眼验证，无自动化测试框架
