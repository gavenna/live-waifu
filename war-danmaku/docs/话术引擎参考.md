# 话术引擎参考

> Announcer 模块完整话术清单 + 调度规则。模板引擎 + LLM 双路径。
> 代码位置: `server/announcer/`

## 架构概览

```
GameEngine 事件 → Announcer.handleEvents()
  ├── 高频事件 → templateEngine.js（模板，随机选取）
  ├── 城堡伤害 → 累积缓冲 → 阈值触发
  ├── 定期战况 → 30s 间隔 → LLM 优先，降级模板
  └── 阶段切换 → enqueuePhase（冷却去重）
         ↓
    Scheduler 优先级队列 → 去重/防抖/溢弃
         ↓
    _speak() → TTS 生成 → waifu-agent WS 中继
```

**游戏循环**: ROUND_END → COUNTDOWN(30s) → PLAYING → ROUND_END → ...（WAITING 仅服务器首启时出现一次）

### 两条生成路径

| 路径 | 引擎 | 用途 | 频率限制 |
|------|------|------|---------|
| 模板 | `templateEngine.js` | 礼物/击杀/攻城/阶段切换等高频事件 | 无上限，秒出 |
| LLM | `llmEngine.js` | 战况分析/拱火/弹幕互动 | 30s 一次，超时 10s 降级 |

## 优先级体系

| 优先级 | 事件类型 | 说明 |
|--------|---------|------|
| P10 | `gift` | 礼物感谢 — 永不防抖，每笔必播 |
| P9 | `comeback`, `global_skill`, `chest_open`, `chest_reveal` | 翻盘/技能/盲盒 — 高紧迫兴奋事件 |
| P8 | `spawn_preview`, `final_2min` | 高级兵预告/最后2分钟 |
| P7 | `siege`, `castle_hit` | 攻城/城堡受损 — 防抖 5s |
| P6 | `kill_multikill` | 连杀（≥3杀触发） — 防抖 4s |
| P5 | `join`, `random_event`, `follow` | 加入阵营/随机事件/关注 |
| P4 | `kill` | 普通击杀（当前未启用） |
| P3 | `phase` | 阶段切换（COUNTDOWN/START/END） |
| P2 | `periodic`, `opening`, `countdown_recruit` | 定期战况/开场拉人/倒计时招募 — 可能被 LLM 替代 |

> 免费民兵 `spawn` 永远静默，不触发话术。

## 调度规则

### 防抖

| 事件类型 | 冷却时间 | 备注 |
|---------|---------|------|
| 礼物 (`gift`) | **无冷却** | 钱的事不能等 |
| 击杀/连杀 | 4s | 同类事件最小间隔 |
| 攻城/城堡 | 5s | 同类事件最小间隔 |
| 其他事件 | 8s | 通用冷却 |
| 阶段消息 | 15s | 同一个 phaseKey 去重 |

### 队列

- 最大容量: **10 条**
- 溢出策略: 丢弃最低优先级非礼物条目
- 批次窗口: **100ms** — 同 tick 内事件先排队，窗口关闭后取最高优先级播报
- 播报间隔: 当前音频播完 + **500ms** 空隙 → 下一条

## LLM 引擎

> 代码: `server/announcer/llmEngine.js`

### 配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LLM_API_URL` | `https://api.deepseek.com/v1/chat/completions` | API 地址 |
| `LLM_MODEL` | `deepseek-chat` | 模型 |
| `LLM_TIMEOUT` | 10000ms | 请求超时 |
| `LLM_INTERVAL` | 30000ms | 最小调用间隔 |
| `LLM_ENABLED` | true | 是否启用 |

### System Prompt 要点

- 风格: 活泼有感染力，体育比赛解说式
- 拱火: "红方这么菜的吗" "蓝方大哥在哪"
- 限制: 每句 ≤30 字，口语化
- 标签: `[emotion]` 控制表情，可选 `[motion:group]` 触发动作

### 三种调用模式

| 模式 | 触发条件 | 输出 |
|------|---------|------|
| `analysis` | 双方差 ≤30% | 客观战况分析 |
| `trash_talk` | 双方差 >30% | 拱火调侃落后方，刺激消费 |
| `danmaku_reply` | 弹幕内容传入 | 接观众弹幕互动 |

### Prompt 上下文

传给 LLM 的数据:
- 红蓝双方人数 + HP 百分比
- 三线战线位置（北境/王道/河谷 ± 数值）
- 最近 5 条事件摘要
- 当前阶段

### 输出解析

格式: `[emotion][motion:group] 口语文本`

示例:
- `[surprised][motion:TapBody] 红方城堡只剩30%了！蓝方冲啊！`
- `[happy] 蓝方大哥终于出手了！战局要变！`

## 城堡伤害缓冲机制

城堡伤害不逐击播报，而是累积到缓冲区：

- 累积伤害 ≥ **100** → 播报
- 距上次播报 ≥ **15s** → 强制播报
- HP 跌破 **50%** 或 **25%** → 播报

避免攻城锤每击都触发 1 条播报导致刷屏。

## 连杀追踪

- 同一 `killerId` 每次击杀递增
- **10s** 内无击杀 → 重置计数
- ≥ **3** 连杀 → 触发 `kill_multikill` 话术
- 新回合开始 → 清空全部追踪
