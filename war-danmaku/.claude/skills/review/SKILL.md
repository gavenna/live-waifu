# /review — 体验审查

对 war-danmaku 做完整的体验审查。检查维度：脚本可查 vs 人眼判断。

## 审查维度

### 脚本可查（自动验证）

| 维度 | 验证方法 |
|------|---------|
| 弹幕延迟 | server 日志对比弹幕到达时间 → 兵种生成时间 |
| 平衡触发 | 模拟人数差 3:1 → 确认动态平衡生效 |
| 时长控制 | 统计 10 局时长 → 目标 15-20 分钟 |
| WS 稳定性 | 模拟断连 → 确认重连机制生效 |

### 人眼判断（手动体验）

| 维度 | 检查点 |
|------|--------|
| 画面冲击力 | 高级兵种（巨人/龙骑士）出场特效是否够震撼 |
| 节奏感 | 是否有"无聊时刻"（连续 2 分钟画面无变化） |
| 头像展示 | 送礼者头像是否清晰、停留时间是否够长 |
| 弹幕可读性 | 弹幕滚动速度是否合适、文字是否清晰 |
| 阵营识别 | 红蓝双方是否一眼能区分 |
| 主播友好 | 排行榜是否清晰可念、事件播报是否及时 |

## 输出格式

```
## 体验审查报告

### 自动验证
✓ 弹幕延迟: 平均 800ms（正常范围）
✓ 平衡触发: 正常
⚠ 时长控制: 3/10 局超过 30 分钟

### 人眼判断
⚠ 巨人出场特效不够震撼（建议加屏幕震动）
✗ 排行榜字体太小，OBS 上看不清

### 建议
1. 缩短单局上限到 25 分钟
2. 巨人加屏幕震动效果
3. 排行榜字体从 14px → 20px
```
