# Art Bible — war-danmaku 视觉风格指南

> 本文档是项目所有视觉资产的唯一标准。任何精灵图、背景、图标、特效都必须遵守此规范。
> 改这里 = 改整个游戏的视觉方向。锁定后才开始批量生产。

---

## 一、风格定义

| 维度 | 规范 |
|------|------|
| **核心风格** | dark fantasy pixel art, 32-bit era aesthetic |
| **子风格** | medieval warfare, gritty but readable |
| **参考** | 《Kingdom Rush》兵种清晰度 + 《Darkest Dungeon》暗黑氛围 |
| **透视** | **正侧视**（side view），所有战斗单位统一面朝右 |
| **描边** | 1px 深色外轮廓（#1a1a1a），内部不描边 |
| **光照** | 左上 45° 平行光源，阴影统一向右下投射 |
| **背景** | 所有精灵图为透明 PNG |

### 风格关键词（注入每个生成 prompt）

```
dark fantasy pixel art game sprite, side view facing right,
32-bit era aesthetic, Kingdom Rush style clarity,
single character isolated, transparent background,
consistent top-left lighting, 1px dark outline,
clean readable silhouette
```

## 三、尺寸规范

| 类型 | 画布尺寸 | 单位实际占比 | 兵种 |
|------|---------|-------------|------|
| 小型单位 | 512×512 | 60-70% 画布高度 | 民兵、剑士、弓手 |
| 中型单位 | 512×512 | 70-80% 画布高度 | 骑士（含马）、皇家卫队 |
| 大型单位 | 768×768 | 65-75% 画布高度 | 岩石巨人、龙骑士 |
| 器械 | 768×512 | 70-80% 画布宽度 | 投石车、攻城锤 |
| 技能图标 | 512×512 | 居中 80% | 火矢齐射、天神之怒 |
| 城堡 | 1024×512 | 80% 画布 | 双方城堡 |
| 背景 | 1920×1080 | 全画布 | 战场全景 |

### 相对比例关系

```
民兵 ≈ 剑士 ≈ 弓手（标准人身高）
骑士 ≈ 1.3× 标准人（含坐骑）
皇家卫队 ≈ 1.2× 标准人（重甲）
投石车 ≈ 2× 标准人宽
岩石巨人 ≈ 2.5× 标准人高
龙骑士 ≈ 3× 标准人高（含龙翼展开）
```

## 四、兵种设计规范

### 4.1 共性要求

- 所有地面兵种：双脚站立，面向右
- 骑兵：马身侧向右，骑手面朝右
- 远程：弓已拉满或箭已上弦
- 盾牌：展示正面纹章（炎龙 = 火焰龙纹 / 霜狼 = 冰霜狼纹）
- 武器：清晰可见，不被身体遮挡

### 4.2 各兵种区别特征

| 兵种 | 必须包含 | 禁止 |
|------|---------|------|
| **民兵** | 草叉或短矛，布衣，无盔甲 | 不能有金属甲、华丽装饰 |
| **剑士** | 长剑，锁子甲，圆盾 | 不能骑马、不能有重甲 |
| **骑士** | 战马（棕/黑），骑枪，板甲 | 马不能太矮，骑枪不能太短 |
| **弓手** | 长弓，箭袋，皮甲 | 不能有近战武器为主 |
| **投石车** | 木质车架，石弹，4 轮 | 不能是人形 |
| **皇家卫队** | 全身板甲，塔盾（狮纹），长剑 | 不能像普通士兵 |
| **岩石巨人** | 巨石身躯，苔藓，无武器（拳头） | 不能穿盔甲、不能太像人 |
| **龙骑士** | 黑龙，龙翼展开，骑枪，火焰/冰霜元素 | 龙不能太小、不能无翼 |
| **火矢齐射** | 多支燃烧箭矢，天空背景，火焰拖尾 | 不能只有一支箭 |
| **天神之怒** | 神圣闪电/光柱击城，天启氛围 | 不能模糊不清 |
| **攻城锤** | 巨木，青铜锤头，多人推 | 不能像投石车 |
| **矛兵** | 双手持长矛/长枪，轻皮甲，布衣 | 不能有盾牌、不能有金属重甲 |
| **弓兵** | 长弓拉满，背挂箭袋，皮甲 | 不能有近战武器为主、不能重甲 |
| **突袭兵** | 双持短刃，动态奔跑姿态，极轻甲 | 不能站立不动、不能有盾牌 |

### 4.3 阵营变体

红蓝兵种共用同一精灵图（阵营区分通过前端渲染叠加色罩）。

## 五、质量标准

生成后逐项检查：

- [ ] **Silhouette 可读性**：缩到 64×64 仍能辨识兵种
- [ ] **色板一致性**：无超出本文档定义的 hex 范围
- [ ] **比例正确**：同类兵种高度误差 < 10%
- [ ] **风格统一**：看起来像同一款游戏（不是拼凑的）
- [ ] **无 AI 伪影**：手指不粘连、武器不断裂、面部不扭曲
- [ ] **透明背景**：无残留白边/灰底
- [ ] **像素对齐**：边缘清晰，无半透明拖影

**不合格的处理**：记录问题点 → 调整 prompt → 重新生成 → 再次验证。最多重试 3 次，3 次仍不合格 → 标记为"需人工修图"。

## 八、动画帧规范

> Phase 6: 兵种帧动画。图生图 (agnes-image-2.0-flash) 以现有精灵图为底图生成各状态关键帧。

### 8.1 动画状态与帧数

| 状态 | 帧数 | 帧间隔 | 总时长 | 说明 |
|------|:----:|:------:|:------:|------|
| idle | 4 | 150ms | 600ms | 呼吸循环，帧 0 复用现有精灵图 |
| walk | 6 | 100ms | 600ms | 闭口走步循环 (contact→down→passing→up→contact-opp→down-opp) |
| attack | 4 | 120ms | 480ms | 蓄力(1)→挥砍(1)→命中(1)→收招(1) |
| death | 4 | 180ms | 720ms | 受击(1)→踉跄(1)→倒地(1)→静止(1) |

### 8.2 生成方式

使用 `gen-anim-frames.js` 脚本，逐帧图生图：
- 输入: `frontend/assets/sprites/<key>.png`（现有精灵图，base64 URI）
- 模型: `agnes-image-2.0-flash`
- 每帧 prompt: `"Same character, same art style, identical appearance. Only change pose: <姿态描述>"`
- 输出: `frontend/assets/sprites/frames/<key>_<state>_<n>.png`

### 8.3 Sprite Sheet 格式

18 帧水平排列：`[idle×4][walk×6][attack×4][death×4]`

每帧尺寸 = 显示尺寸（SPRITE_DEFS），由 `stitch-sprites.py` 完成拼接。

### 8.4 帧间一致性要求

- 角色外观、颜色、比例必须与底图一致（图生图天然保证）
- 武器/盔甲/盾牌在所有帧中保持相同
- 脚部锚定在同一水平线（stitch 时自动对齐）
- 不支持动画帧的兵种（fireArrow/wrathOfGod/batteringRam/warChest）不生成，回退静态渲染
