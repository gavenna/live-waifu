# /verify — 产品验证

对 war-danmaku 进行行为级回归检测。

## 运行方式

```
/verify            # 自动检测本次改动，运行相关检查
/verify all        # 全量检查
```

## 检查维度

### P0（每次必查，脚本自动化）

| 检查项 | 脚本 | 检查内容 |
|--------|------|---------|
| JS 语法 | `node --check` | 所有改动的 JS 文件语法正确 |
| 弹幕接入 | 模拟弹幕 WS 消息 | server 正确解析并转发 |
| 游戏状态机 | 状态转换日志 | WAITING→COUNTDOWN→PLAYING→ROUND_END 循环正常 |
| WS 推送 | 前端接收日志 | server 推送的状态前端正确接收 |

### P1（手动检查）

| 检查项 | 检查方法 |
|--------|---------|
| 画面渲染 | 浏览器打开 frontend，确认画面完整 |
| 兵种动画 | 模拟各种兵种生成，确认视觉正确 |
| OBS 兼容 | OBS 加浏览器源，确认画面正常 |
| 弹幕展示 | 弹幕滚动区正常显示 |

### P2（实际直播测试）

| 检查项 | 检查方法 |
|--------|---------|
| B站弹幕 | 真实直播间测试弹幕→游戏响应 |
| 礼物映射 | 送礼→兵种生成→头像展示 |
| 单局完整 | 完整一局 15-20 分钟无异常 |
| 排行榜 | 多局后排行榜正确累积 |

## 输出格式

```
✓ 4/4 P0 通过
⚠ 1/4 P1 异常：兵种动画（详见下方）
✗ 未执行 P2
```
