> 用途：把「观众弹幕能召唤的兵种」按 **land 陆 / sea 海 / air 空 / building 建筑** 四类指定范围。
> 主播在下面每个桶的表格里填**要放行的兵种**（填弹幕词 + 引擎类型名），填完即成为召唤白名单。
> 机器可读的全量分类见 `danmaku-relay\battle\unit-categories.json`（由 `tools\gen_unit_categories.js` 生成）。

## 怎么填

- **弹幕词**：观众在直播间发的词（例：`步枪兵`、`夜翼`）。同一兵种可写多个别名。
- **引擎类型名**：单位在 mod 定义里的 `type`（例：`EkInfantryGrunt`）。留空则默认用弹幕词精确匹配。
- 每类下面填你想要的；**不填的类别 = 该类暂不放行**。填完我把它接进召唤白名单（现为 `battle\mod-unit-pool.json`）。
