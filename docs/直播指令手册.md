# 默川直播间 · 弹幕指令手册

> 适用范围：**Rusted Warfare 1.15 + danmaku-relay**（2026-09-19 实机验证版）
> 引擎经济已接入 —— 弹幕召唤**真的扣对应队伍的钱**，钱不够会被**拒绝**并在游戏画面上播报。
> 数据来源：`danmaku-relay/battle/liveSpawner.js`（词表/规则）、`battle/unit-prices.json`（单价）、
> `battle/teams.js`（红=team1 / 蓝=team2）、`battle/index.js`（接口）。

---

## 1. 弹幕怎么写

**格式：`阵营` + `数量`(可省) + `兵种`**

| 写法 | 例子 | 说明 |
|---|---|---|
| 中文简写 | `红3战车` | 最常用 |
| 带「方」 | `红方5坦克` | 「方」可省 |
| 中英混排 | `红3 tank` / `红tank` | 空格随意 |
| 英文 | `red3tank` / `blue2heli` | 红=`red` 蓝=`blue`（不分大小写） |

**规则**

| 项 | 值 | 说明 |
|---|---|---|
| 阵营 | `红`/`蓝`/`red`/`blue` | 必填，拼错则整条忽略 |
| 数量 | 默认 `1` | 写在阵营和兵种之间 |
| 单条上限 | **按单价分档**：≤2万→10 / ≤8万→5 / >8万→2 | 见 `battle/summon-whitelist.json` 的 `summon.tierCaps` |
| 冷却 | 同一观众 **3s** | 见 `summon.cooldownMs`（默认 3000） |
| 阵营级上限 | 每队每轮 **300 兵** | `summon.teamCapPerRound`（防一边倒；`RW_TEAM_CAP_PER_ROUND` 可覆盖） |
| 落点 | 统一**自家指挥中心旁** + 巡逻向敌方基地 | 2026-09-22 起取消"≥2 上前线"双区 |
| 花谁的钱 | **观众独立钱包**（红=team3 / 蓝=team4） | 2026-09-27 分账：观众的钱与 AI 主队隔离，AI 花不到 |

**没被识别的情况**（弹幕被忽略，不扣钱、不出兵）：阵营写错、兵种词不在下表、纯聊天内容。

## 3. 经济怎么算

- **来源**：引擎自己的矿井/资源生成器自动产钱（`extractor` 类，实测 **+18/秒/矿井**）；队伍每秒收入也会实时显示。
- **扣款**：召唤瞬间从**该观众阵营的观众钱包**（红=team3 / 蓝=team4）扣 `单价 × 数量`。2026-09-27 分账后与 AI 主队（team1/2）隔离——AI 花不到观众的钱。
- **余额不足**：**整条弹幕被拒绝**（不出兵、不扣钱），并在**游戏画面上播报**`【经济】红方余额不足：需要 $X，现有 $Y`。
- **实时可见**：游戏画面右上角原生显示**红蓝两队的 `$余额 (+每秒收入)`**，红字=红队、蓝字=蓝队。
- **一键回退**：`danmaku-relay/../relay-window.bat` 里把 `set RW_ECON_ENABLED=1` 改成 `0` ⇒ 回到「免费召唤」，行为与接线前完全一致。

## 4. 送礼 → 直接召唤（2026-09-21 变更）

礼物**按抖币当量分档直接召唤一批兵**（不再加余额）：`≥1000→megaTank / ≥300→mammothTank / ≥50→laserTank / ≥0→heavyTank`，每次召唤 `GIFT_UNITS=10` 个（档表见 `danmaku-relay/battle/giftTiers.js`）。

- 抖音按**抖币**计；B站按**金瓜子**折算（1000 金瓜子 = 1 元 = 10 抖币 ⇒ ÷100）。
- 投该观众**归属阵营**、落自家基地旁 + 巡逻向敌方基地（与弹幕召唤同语义）；**不扣**该队余额——礼物本身就是支付。
- 最低档已是硬兵（heavyTank），直播初期"1 抖币小心心"的人也不觉得白送。

> ⚠️ 历史遗留：`danmaku-relay/config.js` 里的礼物→兵种映射（`swordsman`/`knight`/`giant`…）名字不是本游戏单位，**不参与出兵**（死代码）。

**B站（金瓜子阶梯）**：`≥1000 → giant`、`≥500 → royalGuard`、`≥100 → knight`、`≥10 → swordsman`

**抖音（抖币阶梯）**：`≥3000 → wrathOfGod`、`≥1200 → dragonKnight`、`≥520 → giant`、`≥299 → batteringRam`、`≥199 → fireArrow`、`≥99 → royalGuard`、`≥30 → catapult`、`≥10 → archer`、`≥5 → knight`、`≥1 → swordsman`

> 接线时需要把这些名字换成第 2 节里的引擎单位名（例如 `≥520 → mammothTank`）。

**进房自动加入阵营**：抖音适配器 `AUTO_JOIN_ON_ENTER: true` —— 观众进直播间会被自动编入随机阵营（同一人只编一次）。

## 5. 主播/运营可用的操作（HTTP 接口，默认端口 `8767`）

| 操作 | 请求 | 说明 |
|---|---|---|
| 开始一局 | `POST /api/battle/start` | 可选 body `{"mapFile":"live_dire.tmx"}`；默认地图就是它 |
| 结束当前局 | `POST /api/battle/end` | 立即收场并播报 |
| 看当前状态 | `GET /api/battle/state` | 轮次/状态/秒数/双方兵力 |
| 杀游戏进程 | `POST /api/battle/kill-game` | 卡死时用；下次起局会自动重启 |
| 发条命令给引擎 | `POST /api/battle/exec` | body `{"cmd":"script debug.xxx(...)","waitMs":1200}` |
| **模拟一条弹幕**（测试用） | `POST /api/battle/simulate-danmaku` | body `{"content":"红2战车","userId":"tester","nickname":"测试号"}`<br>⚠️ 字段名是 **`content` / `userId` / `nickname`**（**不是** `text`/`user`）；`content` 留空会回落到内置的 `红 坦克`（于是只有 1 辆）<br>⚠️ **只有对局进行中（FIGHTING）才会被处理** —— 待命状态（IDLE/ENDED）发弹幕会被静默忽略，所以测之前先 `POST /api/battle/start`<br>⚠️ 中文必须用**脚本/工具**发（PowerShell 直发会丢编码） |
| 中继状态 | `GET /api/status` | 直播间连接、订阅数、PID |
| 启/停抖音·B站接入 | `POST /api/start-douyin` `/api/stop-douyin` `/api/start-bilibili` `/api/stop-bilibili` | |
| 看日志 | `GET /api/logs` | 环形缓冲 |
| 自检 | `GET /api/diagnose` | 端口/依赖/配置体检 |
| 保存配置 | `POST /api/config/save` | |

**常用引擎命令**（通过 `/api/battle/exec`）：
- 加钱：`script debug.addTeamCredits(1, 5000)`（红队 +5000；负数即扣钱）
- 设钱：`script debug.setTeamCredits(1, 100000)`
- 造单位：`script debug.createUnit('tank', 1089.0, 997.0, 1, false)`
- 画面播报：`script debug.showMessage('主播说的话')`
- 同盟/敌对：`script debug.setTeamAllyGroup(1, 1)`（同组=同盟）

## 6. 一局里的完整链路（主播视角）

```
观众发弹幕「红3战车」
   → 中继解析：阵营=红、数量=3、兵种=tank
   → 读该阵营**观众钱包**实时余额（引擎每 6 帧落盘的 econ_live.txt 的 team3）
   → 够钱：先扣款 addTeamCredits(3, -1050)，再 spawnPatrol ×3（落 team3，向敌方基地巡逻）
   → 不够：整条拒绝 + 游戏画面播报「余额不足」
   → 屏幕上：红蓝两队 $余额(+收入) 实时刷新，原生显示
   → 一局结束：画面播报胜负 + 贡献榜前三；前三名下一轮头顶带称号/徽章
```

## 7. 出问题时先看这三样

1. **中继日志**：`danmaku-relay/logs/combined.log`（生兵记 `[SPAWN] 红方 tank x3 (花费 $1050 → 余额 $199216)`，拒绝记 `[ECON] 拒绝召唤 …`）
2. **实时经济数据**：`<游戏目录>/econ_live.txt`（`# econ_live <毫秒> <帧>` + 每行 `team <id> <余额> <每秒收入>`）
3. **游戏日志**：`<游戏目录>/lastrun.log`

⚠️ **改动 `danmaku-relay/battle/*.js` 后必须重启中继**（这些文件只在启动时加载）。
