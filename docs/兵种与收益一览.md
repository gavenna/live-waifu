## 一、怎么召唤

弹幕格式：**阵营 + 数量（可省）+ 兵种**，例如 `红3战车`、`蓝方5坦克`、`red2heli`。

| 规则 | 说明 |
|---|---|
| 阵营 | 红 / 蓝（英文 red / blue），必填 |
| 数量 | 默认 1，**单条最多 10** |
| 落点 | 数量 **≥2 落前线**（地图中部交火区，落地就打）；**=1 落自家基地** |
| 冷却 | 同一观众 **500ms** |
| 花钱 | 从**该阵营队伍**的余额里扣「单价 × 数量」；**钱不够整条被拒绝**，画面播报「余额不足」 |
| 不识别 | 阵营写错 / 兵种词不在下表 → 整条忽略（不出兵、不扣钱） |

## 三、互动加余额

给**你所支持阵营**的队伍加钱（归属由你发过的红/蓝弹幕或进房随机决定）：

| 互动 | 加多少 |
|---|---|
| 点赞 | **+1000** / 次（0 = 关闭） |
| 关注 | **+50000** / 次（0 = 关闭） |
| 送礼物 | **当前不参与加余额**（中继只处理 弹幕/点赞/关注/进房，礼物暂未接线） |

## 四、一局怎么走

- 自动开局 → 红蓝对战 → 一方基地被拆 或 超时（默认 5 分钟）判胜负 → 自动开下一局。
- 结束时播报：哪方获胜、第几轮、用时、双方兵力。
